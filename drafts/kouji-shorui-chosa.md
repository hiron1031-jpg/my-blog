## 2. 本省「工事関係書類一覧表」（H23.6.1）

https://www.mlit.go.jp/tec/sekisan/sekou/pdf/230601kouzikankeisyoruiichiran1.pdf

| | |
|---|---|
| 日付 | **H23.6.1**（2011年6月1日） |
| 分量 | 4ページ・**全86項目** |
| 列 | 作成時期／種別／No／書類名称／**書類作成の根拠**／標準様式（様式No）／**書類作成者（発注者・受注者）**／**提出**／**提示**／その他／備考 |

### ⭐ この表のいちばんの価値

**「提出」と「提示」が別の列になっている。**

| | 意味 |
|---|---|
| **提出** | 監督職員に出す |
| **提示** | 見せるだけ。出さない |

例：**産業廃棄物管理表（マニフェスト）は No.71 で「提示」**（備考：産業廃棄物を搬出した場合に提示する）

### ⚠️ ただしH23版

**個々の書類名を「現在も必要」と書いてはいけない。** 構造（提出／提示の区別、誰が作るか）の説明にとどめる。

> 国土交通省所管事業の執行における円滑な発注及び施工体制の確保に向けた具体的対策における**工事書類の簡素化の取扱いについて**

（令和2年5月7日、国地契第6号、**国官技第29号**、国営管第61号、国営計第15号、国北予第7号 の別紙(3)②に関するもの）

### 検査書類限定型モデル工事

> 技術検査官は、検査時に**下記の10書類に限定**して資料検査を行う。

| | |
|---|---|
| ① | 施工計画書 |
| ② | 施工体制台帳（下請引取検査書類を含む。） |
| ③ | 工事打合せ簿（協議） |
| ④ | 工事打合せ簿（提出） |
| ⑤ | 工事打合せ簿（承諾） |
| ⑥ | 出来形管理図表 |
| ⑦ | 品質管理図表 |
| ⑧ | 品質規格証明資料 |
| ⑨ | 品質証明書 |
| ⑩ | 工事写真 |

> ※上記書類は、**検査用に作成するのではなく、適時、監督職員に提出した資料をとりまとめたもの**とする。

**対象外**：低入札価格調査対象工事／監督体制強化工事／施工中に改善指示が発出された工事

## 4. 東北地整「工事関係書類簡素化のポイント」第三版（令和6年3月）

http://www.thr.mlit.go.jp/bumon/b00097/k00910/kyoutuu/syoruikansokapointR6.3.pdf

**16ページ・全16項目。** いまのところ**いちばん具体的で新しい**。

### 適用範囲（本文より）

> **東北地方整備局（港湾空港関係、営繕関係を除く）が発注する全ての工事**

> ※ただし、**受注者の社内で必要とされる工事書類の作成を妨げるものではない。法令等に規定された書類の作成は適正に行うものとする。**

⚠️ **この但し書きが重要。** 「簡素化された＝作らなくていい」ではない。

### 項目別の要点（本文の文言）

| | 項目 | 要点 |
|---|---|---|
| 1 | 施工計画書 | **変更施工計画書は、工期や数量等の軽微な変更の場合は提出不要。変更箇所のみを抜粋して提出してよい** |
| 2 | 施工体制台帳等 | 提出は様式・添付資料のみ。**発注者への提出は月1回に集約可能。ただし元請特定建設業者としての法的責務を緩和するものではない** |
| 3 | 原則電子化 | **電子と書類の二重提出を行わない。** R4.3.15以降適用開始。※品質証明・カタログ・見本など第三者から受け取った紙は電子化しない |
| 4 | 二重防止 | **工事着手前に事前協議**（誰が作るか／紙か電子か） |
| 6 | 工事打合せ簿 | **共通仕様書やHP等で入手可能な一般的な基準類の添付は不要。提示については打合せ簿を作成する必要はない** |
| 7 | 材料確認願 | **特記仕様書に記載された指定材料のみ提出。監督職員等が臨場した場合は写真添付は不要。JISマーク表示品はマークの写真の提示でよい** |
| 9 | 段階確認書 | **臨場した場合は写真添付は不要。出来形管理写真も省略。段階確認のために新たに資料を作成する必要はない** |
| 11 | 工事履行報告書 | **根拠資料の添付は不要**（中間前払い金請求時は必要） |
| 13 | 工事検査 | **「書類限定検査」で10種類に限定。** 検査職員は電子データで検査し、紙の提示を求めない |
| 14 | 品質証明 | **添付書類は不要。品質証明員及び受注者の押印は不要** |
| 15 | ICT活用工事 | **使用機器やソフトのカタログ添付は不要。3次元設計データチェックシートのみ提出、チェック入り図面は不要** |
| 16⑫ | — | **工事関係書類の押印廃止** |

> 📌 13の10書類は、令和2年の本省事務連絡の10書類と**ほぼ同じ**（⑥⑦⑧の並び順だけ異なる）。
> **本省の試行 → 地整で標準化**、という流れが読み取れる（これは資料の対照からの**推定**であって、そう書かれているわけではない）。

## 5. 「44種類→10種類」について

Web検索の要約に「完成工事における工事検査書類を44種類から10種類に限定する工事を原則実施し、『書類限定検査』として標準化」という記述があった（令和6年度 国交省 土木工事・業務の積算基準等の改定 関連）。

⚠️ **「44種類」の出どころは原本で未確認。** 検索結果の要約でしか見ていない。**記事に書くなら原本を確認すること。**

**10種類のほうは、本省の事務連絡と東北地整の資料の両方で原本確認済み。**

## 8. 記事にするときの方針

### 書いてよいこと（原本確認済み）

- **「提出」と「提示」は違う**という構造
- **書類ごとに作成者（発注者／受注者）が違う**という構造
- **簡素化が7回行われている**という事実と改定履歴
- **書類限定検査の10種類**（本省・東北地整の両方で確認済み）
- **着工前に事前協議する**という実務の答え
- 東北地整の具体的な簡素化ルール（**「東北地整の資料では」と明記して**）

### 書いてはいけないこと

- ❌ **H23の86項目を「いま必要な書類」として並べる**
- ❌ **一地整のルールを「全国共通」として書く**
- ❌ **「44種類→10種類」を原本未確認のまま数字で書く**
- ❌ **「この一覧で足りる」と読める書き方**

### 免責に入れる文言（案）

> ⚠️ **工事書類の扱いは、発注者ごとに違います。**
>
> 国土交通省は本省が「土木工事共通仕様書（案）」を各地方整備局に通知し、**各地方整備局が自局のマニュアルを定めています。** 都道府県・市町村はさらに独自のものを持っています。
>
> また、**書類の簡素化は繰り返し行われています。** 東北地方整備局の資料によれば、土木工事書類作成マニュアルは平成21年の策定以降、**7回改定**されています。
>
> **この記事は全体像をつかむためのものです。** 実際に必要な書類は、**必ず当該工事の発注者が出している最新のマニュアル・一覧表と、共通仕様書・特記仕様書で確認してください。** そのうえで、**着工前に監督職員と「提出・提示する書類」「紙か電子か」を協議してください。**
>
> なお、簡素化は**発注者に提出する書類**の話です。東北地方整備局の資料にも「**受注者の社内で必要とされる工事書類の作成を妨げるものではない。法令等に規定された書類の作成は適正に行うものとする**」と書かれています。
>
> 筆者は行政書士でも、発注者の立場の人間でもありません。
