# サムネイル生成の指示文（ChatGPT用）

作成日: 2026-09-11
用途: サムネイルが使い回しになっている5記事ぶん

## 使い方

1. ChatGPTに下の「共通の指示」＋「各記事の指示」を**まとめて1つ**貼る
2. 生成された画像をダウンロード
3. **指定のファイル名**に変更して `my-blog/public/images/posts/` に置く
4. 監督から「置いたよ」と一声もらえれば、私が記事に設定してデプロイします

⚠️ 画像内の文字は崩れることがあります。**日本語が正しく出るまで数回作り直す**のが普通です。

---

## 共通の指示（毎回そのまま貼る）

```
日本の建設業ブログ「土木のトリセツ」の記事サムネイル画像を作ってください。

【必須の仕様】
- 横長 16:9（1672×941px相当）
- 日本語の文字を大きく、正確に、読みやすく配置すること
- 既存シリーズと同じテイスト：明るく親しみやすいフラットイラスト、彩度高め、太い袋文字（白フチ＋濃い色）の見出し
- マスコットキャラクター：黄色または白のヘルメットをかぶった、丸くて可愛い茶色のビーバー。作業服姿。日本のゆるキャラ風
- 実写ではなくイラスト。写真的リアリズムは避ける
- 商品名やメーカーのロゴは入れないこと（架空のロゴも不可）
- 画面の隅に小さく余白を取り、文字が切れないようにすること
```
