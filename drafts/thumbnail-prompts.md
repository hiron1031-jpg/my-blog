# サムネイル生成の指示文（ChatGPT用）

更新日: 2026-09-13

## 方針：シンプルに作る

当初は周囲にアイテムを8個並べる構成にしていましたが、**要素が多いと日本語が崩れます**。
これ以降は **「タイトル＋マスコット＋要素3つまで」** を基本にします。

読者が見るのは記事一覧の小さいサムネイルなので、**文字が大きく少ないほうが伝わります。**

---

## 共通の指示（毎回そのまま貼る）

```
日本の建設業ブログ「土木のトリセツ」の記事サムネイル画像を作ってください。

【必須の仕様】
- 横長 16:9（1672×941px相当）
- 日本語の文字は大きく、少なく、正確に。読みやすさを最優先
- テイスト：明るく親しみやすいフラットイラスト、彩度高め、
  太い袋文字（白フチ＋濃い色）の見出し
- マスコット：黄色か白のヘルメットをかぶった、丸くて可愛い茶色のビーバー。
  作業服姿。日本のゆるキャラ風
- イラストのみ。写真的リアリズムは避ける
- 商品名・メーカーのロゴは入れない（架空のロゴも不可）
- 画面の端に余白を取り、文字を切らない

【構成のルール】
- 文字要素は「メインタイトル」「サブタイトル」「短いひとこと1つ」の3つまで
- 小物は多くても3つまで。並べすぎない
- 画面の半分は背景とマスコットに使い、ゆとりを持たせる
```

## ⑥ 造園の経験記述シリーズ 4枚（作り直し）

**なぜ作り直すか**：記事は「R6から出題なし」に直したのに、サムネイルが「経験記述の書き方！」を推したままでした。記事一覧で絵とタイトルが逆のことを言っている状態です。

**4枚とも共通で入れる帯**（ここが今回の目的です）

```
画面の下側または右上に、赤またはオレンジの帯を1本。
帯の中の文字：「R6から出題なし」
太い白文字で、小さくても読める大きさにしてください。
帯は目立たせますが、メインタイトルより小さくします。
```
