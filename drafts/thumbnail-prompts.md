# サムネイル生成の指示文（ChatGPT用）

更新日: 2026-09-13

## 方針：シンプルに作る

当初は周囲にアイテムを8個並べる構成にしていましたが、**要素が多いと日本語が崩れます**。
これ以降は **「タイトル＋マスコット＋要素3つまで」** を基本にします。

読者が見るのは記事一覧の小さいサムネイルなので、**文字が大きく少ないほうが伝わります。**

---

## 共通の指示（毎回そのまま貼る）

```
日本の建設業ブログ「土木のトリセツ」の記事サムネイル画像を作ってください。

【必須の仕様】
- 横長 16:9（1672×941px相当）
- 日本語の文字は大きく、少なく、正確に。読みやすさを最優先
- テイスト：明るく親しみやすいフラットイラスト、彩度高め、
  太い袋文字（白フチ＋濃い色）の見出し
- マスコット：黄色か白のヘルメットをかぶった、丸くて可愛い茶色のビーバー。
  作業服姿。日本のゆるキャラ風
- イラストのみ。写真的リアリズムは避ける
- 商品名・メーカーのロゴは入れない（架空のロゴも不可）
- 画面の端に余白を取り、文字を切らない

【構成のルール】
- 文字要素は「メインタイトル」「サブタイトル」「短いひとこと1つ」の3つまで
- 小物は多くても3つまで。並べすぎない
- 画面の半分は背景とマスコットに使い、ゆとりを持たせる
```

## ① 施工写真の撮り方

**ファイル名: `sekou-shashin.png`**

```
【この画像の内容】

メインタイトル：「施工写真の撮り方」
サブタイトル：「写真がないと検査に落ちる」
ひとこと（吹き出し）：「迷ったら撮る！」

構図：
画面の右側に、ビーバーのマスコットが立っている。
片手に工事用の白いホワイトボード、もう片手にカメラを持ち、
これから撮影するところ。真剣だが前向きな表情。

背景：建設現場。組まれた鉄筋がぼんやり見える程度。
ごちゃごちゃさせず、シンプルに。

小物は入れない（マスコットが持っているホワイトボードとカメラのみ）。

配色：ブルーを基調に、ヘルメットの黄色をアクセント。
```

## 今後の記事でも使える型

新しい記事のサムネイルが必要になったら、この形で指示します。

```
メインタイトル：（記事の主題を短く）
サブタイトル：（ひとことで補足）
ひとこと（吹き出し）：（読者に一番伝えたい一言）

構図：画面の片側にマスコット。反対側にタイトル。
背景はテーマが分かる程度にシンプルに。
小物は3つまで。
```
