# GA4「キーイベント」設定手順（監督の作業・5分）

作成日: 2026-09-02

## なぜやるのか

GA4のレポートを見ると、**キーイベントも合計収益も全ブラウザで0**でした。
`affiliate_click` というイベントは飛んでいるのに、**GA4側で「これが成果です」と登録していない**状態です。

このままだと「どの記事から・どのブラウザから売れたか」が一切わかりません。

⚠️ **訂正（2026-09-05）**：当初「過去のデータにも遡って適用される」と書いていましたが、**誤りでした。
キーイベントとして数えられるのは、設定した時点より後のクリックだけです。** 過去分は遡って計上されません。
（イベント自体は記録され続けているので、`affiliate_click` の生の件数は過去分も見られます）

---

## 手順

1. GA4を開く → 左下の**歯車マーク（管理）**をクリック
2. 「データの表示」の中の **「イベント」** をクリック
3. 一覧から次のイベント名を探す（クリック実績があれば載っています）

| イベント名 | 何のクリックか |
|---|---|
| `affiliate_click` | note商品・アフィリエイトのクリック全般 |
| `mobile_handoff_click` | PC→スマホ誘導のリンククリック |

4. `affiliate_click` の行の右にある **「キーイベントとしてマークを付ける」のスイッチをオン**にする

これだけです。

---

## 設定後に見られるようになるもの

数日データがたまると、以下が分かります。

- **どのブラウザから売れているか**（Edge＝職場PC vs Safari＝スマホ）
- **どの記事から売れているか**
- **QR経由のスマホ流入が成果につながっているか**

### QR経由の流入の見かた

QRのURLには目印（utm）を付けてあります。

「レポート」→「集客」→「トラフィック獲得」で、**参照元/メディアが `qr / pc`** の行を探してください。
これがPCからスマホに移ってくれた人の数です。

- `sumaho_quiz` … クイズページのQR
- `sumaho_pdf` … 過去問ダウンロードページのQR

---

## 補足：イベントが一覧に出てこない場合

イベントは**実際にクリックされてから最大24時間ほど**で一覧に現れます。
見つからないときは翌日また開いてみてください。
