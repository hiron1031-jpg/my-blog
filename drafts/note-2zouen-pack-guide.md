## なぜ今つくるのか

9月の売上を見ると、**パックが売上の90%（12,340円／13,640円）**でした。そして一番売れたのは——

| パック | 単価 | 9月の販売 |
|---|---|---|
| **2級土木 合格パック** | 1,480円 | **5本** |
| 1級造園 合格パック | 1,480円 | 2本 |
| 1級土木 合格パック | 1,980円 | 1本 |

**2級土木が最多**です。そして2級土木の後期は**一次・二次が同日**。**2級造園も11月15日に同日実施**で、まったく同じ構造です。

それなのに、**2級造園だけパックがありません。** ここが今いちばん大きな穴です。

## ⚠️ 最重要：無料記事はマガジンに入れない

**無料記事を買い切りマガジンに入れると、その無料記事が自動的にマガジン価格（有料）になります。**
2級造園の無料「練習用解答用紙」は入口なので、**絶対にマガジンに入れないでください。**

✅ マガジンに入れるのは **有料2記事＋新規キット1記事の合計3記事だけ** です。

## 手順1: キット記事を新規作成（10分）

### そもそも「有料エリア」とは

noteの有料記事は、**1本の記事の途中に線を引いて、上下で分ける**しくみです。

```
┌────────────────────────┐
│  記事タイトル               │
│                            │
│  ここは誰でも読める          │ ← 買う前の人に見せる部分
│  （導入・何が入っているか）   │
│                            │
├──── 有料ライン ────┤ ← ここに線を引く
│                            │
│  ここは買った人だけ          │ ← PDFはこの中に置く
│  （中身・PDF）              │
└────────────────────────┘
```

**PDFを有料ラインより上に置くと、誰でもダウンロードできてしまいます。** ここだけ気をつけてください。

### 実際の手順

1. noteで**新規記事**を作成
2. 見出し画像: `note-assets/thumbnail-kit-2zouen.png`（※指示文は `drafts/thumbnail-prompts.md` の⑨）
3. 本文: `drafts/note-2zouen-pack-kit.md` をコピペ
   - **「※」で始まる行と、「★★」で始まる行は貼らないでください**（編集メモです）
4. **有料ラインを引く**
   - 本文に貼った `==========` と `★★ ここに「有料ライン」を引く` の位置にカーソルを置く
   - 段落と段落の間にカーソルを置くと、左側に **「＋」ボタン** が出ます
   - 「＋」を押すと挿入メニューが開くので、**「有料エリア設定」**（または「ここから先は有料」）を選ぶ
   - 線が引かれたら、目印の `==========` の5行は**削除**してください
5. **PDFを添付**（有料ラインより**下**に置く）
   - `★★ ここにPDFを添付する` と書いた位置にカーソルを置く
   - 同じく **「＋」ボタン** → **「ファイル」**（またはクリップのアイコン）
   - `note-assets/kit/2zouen-r8-goukaku-kit.pdf` を選ぶ
   - 目印の `★★` の2行は**削除**してください
6. 右上の **「公開に進む」** を押す
7. 販売設定で **「有料」** を選び、価格に **1480** と入力
8. ハッシュタグ: #2級造園施工管理技士 #造園 #第二次検定 #独学 #資格試験
9. 公開

### 公開したら、必ず確認してください

**ログアウトした状態（またはシークレットウィンドウ）で記事を開く**と、買っていない人からどう見えるか分かります。

- [ ] PDFが**見えていない**（＝有料ラインより下にある）
- [ ] 導入と「何が入っているか」は**読める**
- [ ] 価格が1,480円になっている

**PDFが見えていたら、有料ラインの位置が間違っています。** PDFを線より下へドラッグして移動してください。

> 💡 note の画面は更新されることがあります。「＋」ボタンの中の名前が違っていたら、**「有料」「ライン」「ファイル」**という言葉を探してください。分からなければ画面のスクリーンショットを送ってください。一緒に見ます。

💡 キットPDFの中身は他資格と同じ構成ですが、**2級造園固有**に作り直してあります（同日受験・維持管理の比率・問題1／問題2の2問構成）。中身の再チェックは不要です。

## 補足：なぜ1,480円か

- 2級土木・1級造園と同額。**同じ「2級」「造園」で価格が違うと説明しにくい**
- 2級造園の受験者層は若手・見習いが多く、**1,980円は心理的に重い**
- 単品合計2,280円からの「800円お得」は他パックと同じ割引額
