### ここから分かること

- **上位の半分が国交省のPDF。** 検索した人は古いPDFにたどり着いている
- **民間の上位はSaaSのオウンドメディア。** 目的は自社サービスへの誘導
- **「一人親方」向けが2本**入っている＝独立した需要がある

### 🔴 厳しい事実

- **グリーンサイトが220.2K。** 安全書類の電子化はかなり進んでいる
- **`constr-greenfile.com` が「安全書類が完全無料」で全建統一様式を配っている**
- **`anzenshorui.com` が「法令で必要な書類と元請指定の書類の違い」をすでに書いている**
  （＝こちらが「記事の肝」と考えていたネタ）

**→「様式Excelを配る」だけでは勝てない。無料で配っている先行者がいる。**

### ⭕ それでも勝てる点

1. **1位の国交省PDFが古い**（4,000万円・法第24条の7のまま）。**正しい現行数字を法令本文の出典つきで出せる**
2. SaaSの記事は**自社サービスに誘導して終わる**。うちは**中立**で、判定表まで出せる
3. **公共工事×中小**に絞る。SaaSは全方位なので、この絞り込みは無い
4. **下請として出す側をやってきた**人が書く（SaaSの記事には無い）

## 4. 収益化の計画（修正版）

### 🔴 前提が変わった

[yuryo-keikaku-2026-11-12.md](yuryo-keikaku-2026-11-12.md) では
「単品1,980円×6 → セット9,800円」としていたが、**無料で様式を配る競合がいると判明した。**

**「様式Excel」を単品で売るのは厳しい。**

### 売れるのは「様式」ではなく「判断」

| 売れないもの | 売れるかもしれないもの |
|---|---|
| ❌ 白紙の様式 | ⭕ **うちの現場は要るのか／要らないのか**（判定） |
| ❌ 記入例だけ | ⭕ **法令の義務と元請の要求の線引き** |
| ❌ 全建統一様式の配布 | ⭕ **公共工事×中小に絞った手順**（SaaSは全方位） |
| | ⭕ **下請から集めるときの頼み方**（監督にしか書けない） |

### 段階を踏む（作り込む前に測る）

| 段階 | やること | 判断 |
|---|---|---|
| **第1** | **記事3本を無料で出す** | 2027年1月末に表示数を測る |
| **第2** | 合計が**月1,000表示**を超えたら、商品の設計に入る | 超えなければ商品化しない |
| **第3** | 商品は**「判断と手順」**。様式は**おまけ**（国交省の作成例をPDL1.0で加工） | |

### 収益の見込み（正直な数字）

記事1が Bing の約21Kの **5%** を取れたと仮定すると：

| | |
|---|---|
| 月間表示 | 約1,050 |

| 購入率2%・単価3,980円 | **月18,300円** |

**⚠️ これは「5%取れたら」の話。取れる保証はない。** 上位は国交省PDFとSaaS。
**第1段階の実測まで、商品は作らない。**

**「悩みは実在するが、検索されない」典型。** 検索からは客が来ないので、**単独商品にはならない。**

ただし**価値がないわけではない**。置き場所を変えれば効く：

| 置き場所 | 理由 |
|---|---|
| ⭕ **パックのおまけ** | 既に買う気のある人には刺さる。**買う理由を増やす** |

| ⭕ 記事の中の1章 | KY活動の記事に足す |
