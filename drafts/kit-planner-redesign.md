# 直前総仕上げキット「学習プランナー」の作り直し設計

2026-11-05 設計／**着手は11/16以降**（11/15の2級造園が終わってから）

---

## なぜ作り直すのか

### 現状の問題

いまの `note-assets/kit/*-r8-goukaku-kit.html` p.4 はこうなっている。

| 週 | やること | 開始日メモ |
|---|---|---|
| 第1〜2週 | 経験記述：工事概要＋3テーマを下書き | （空欄） |
| 第3週 | 清書し、指定字数・行数に収める | （空欄） |
| 第4週 | 解答解説で問題2〜9をインプット | （空欄） |
| 第5週 | 暗記シート反復＋選択問題を決める | （空欄） |
| 第6週 | 練習用解答用紙で通し演習 | （空欄） |
| 直前3日 | NG総まとめ・持ち物準備 | （空欄） |

**「試験日から6週間逆算して開始日を記入」＝日付ベース。**

現場で働く読者にとって、**「11月8日に経験記述を清書する」は守れない。**
その日に何をしているかは、現場が決めるから。

### 直す2つの理由

1. **守れない形になっている**（挫折する設計）
2. **年度依存がある**（試験日が入るので毎年作り直し）

**if-then型（合図ベース）にすると、両方同時に解決する。**
「休憩が始まったら」に試験日は出てこない＝**毎年の差し替えが不要になる。**

## 設計原理

> **いつ・どこで・何を を、シート側で固定する。使う人の意志を要求しない。**

根拠は監督の実体験（[経験談の原本](kantoku-story.md) ⑩⑪）。
**研究の引用はしない**（数字の裏が取れていない。2026-11-05 確認）。
監督が自力で同じ形にたどり着いていたので、**体験として書けば足りる。**

## 読者の挫折ポイント → 対応表

**全部、監督が実際にぶつかったもの。** 作り話は1つもない。

| # | 挫折ポイント（監督の言葉） | シート側でどう潰すか |
|---|---|---|
| 1 | **仕事が終わってからじゃ手につかない。疲れてそんな気力ない** | **夜のマスを作らない。** 記入欄を休憩時間だけにする |
| 2 | 机に向かうという選択肢が、そもそも頭に浮かばない | **机を前提にしない。** 「外・車」を記入例に明記 |
| 3 | 「11月8日に清書」が守れない | **日付欄を廃止。** 「合図」欄に置き換える |
| 4 | **経験記述をゼロから書き出すのはかなり困難だった** | 「書く」ではなく**「例文の型に自分の現場を入れる」**を手順にする |
| 5 | **何度も諦めかけた** | **1日1マス・最大5項目。** 途切れても戻れる形にする |
| 6 | 他の人は何もしていなかった。ずっと「やらなきゃ」と言っていた | **「やらなきゃ」を書く欄を作らない。** 合図と行動だけ |
| 7 | 3日空くとそのまま終わる | **週単位の達成欄**（日割りにしない）。1日飛んでも破綻しない |

## 新しいシートの形（A4 1枚・書き込み式）

### 上部：自分の合図を決める（1回だけ書く）

> **この3行を埋めたら、あとは考えなくていい。**

| | 記入欄 | 記入例 |
|---|---|---|
| **いつ** | 　　　　が始まったら | **午前の休憩**／**昼を食べ終わったら**／**現場に着いて待ちの間** |
| **どこで** | 　　　　で | **車の中**／**詰所の外**／**休憩所の隅** |
| **何を** | 　　　　を1つ | **過去問クイズ1問**／**暗記シート1枚**／**例文を1回音読** |

⚠️ **「いつ」は時刻を書かせない。** 必ず来る出来事に紐づける。
「19時に」は守れない。「休憩が始まったら」は必ず来る。

### 中央：やることは5つだけ（順番つき）

日付ではなく**順番**で置く。1つ終わったらチェック。

| 順 | やること | できた |
|---|---|---|
| 1 | **経験記述の型を決める**（例文集から、自分に近いものを1つ選ぶ） | ☐ |
| 2 | **自分の現場に中身を入れ替える**（工事名・数量・自分がやったこと） | ☐ |
| 3 | **紙に書いて覚える**（解答用紙に赤ペン → 赤シートで隠す） | ☐ |
| 4 | **問題2〜9を暗記シートで回す**（休憩のたびに1枚） | ☐ |
| 5 | **通しで1回書く**（本番と同じ解答用紙で） | ☐ |

> ⚠️ **1〜2は試験1週間前でも間に合う。** 監督は1週間前に暗記した。
> **早く始められなかったことを、やめる理由にしない。**

### 下部：達成が見える欄（必須）

**家計テンプレの「今月浮いた額」にあたるもの。**
受検者にとっての達成感は「**続いた日数**」ではなく「**手が動いた回数**」。

| | |
|---|---|
| **今週、合図で開いた回数** | ☐☐☐☐☐☐☐（7マス・塗りつぶし式） |
| **覚えた暗記シート** | 　　枚 |
| **書いた経験記述** | 　　回 |

⚠️ **「毎日できたか」を問う欄は作らない。** 空白が並ぶと人はやめる。
**塗った数だけが見える形**にする。

### 最下部：1行だけ

> **一緒に受けた人は、何もしていませんでした。それが普通です。**
> **違うのは、決めてあるかどうかだけ。**

## 年度依存を消すチェック

作ったあと、**この3つが入っていないことを確認する。**

- [ ] 試験日（令和◯年◯月◯日）が**どこにも入っていない**
- [ ] 「第◯週」という**週番号が入っていない**
- [ ] 「残り◯日」の**カウントダウンが入っていない**

→ 全部クリアなら、**来年もそのまま使える。**

> 📌 試験日は、キットの**他のページ（表紙・構成の説明）**に残してよい。
> 差し替えが必要なのはそこだけになるので、作業が激減する。

## やらないこと

❌ **単品で売らない。**

2026-10-29に決定済み：**商品は分けない。合格パック1本で売る。**
9月はパックが売上の90%、10月は75%。単品はほとんど売れていない。
分けると客単価1,480円が500〜800円に下がる。

→ このシートは**パックの中身を強くするため**に使う。

## やってもいいこと（無料版）

**売らずに、入口として配る**なら矛盾しない。

> **「休憩10分の受検プラン」A4 1枚（無料・登録不要）**
> 上部の「いつ・どこで・何を」だけの簡易版。ブログで配布 → パックへ送る。

PDFダウンロードは3か月で**11,194回**。ここに1枚足す価値はある。
**ただし、有料版との差（5項目・暗記シート・NG集）がはっきり分かる形にすること。**
