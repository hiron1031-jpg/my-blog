# 「会社の個人」に売る｜戦略メモ

2026-11-06。監督の方針：**実務は個人ではなく「会社の個人」に売る。1万円以内なら稟議は要らない。**

> ⚠️ この方針は、前に書いた「法人向け（会社と契約する）」より**はるかに良い。**
> 契約書も請求書も営業も要らず、**いまのnoteのまま**で成立する。

---

## noteの仕様確認（2026-11-06 公式ヘルプで確認済み）

| | |
|---|---|
| **価格の上限** | **通常会員：100円〜50,000円**／プレミアム・note pro：10万円 |
| **領収書** | **購入者が自分で発行できる**（設定 → 購入・チップ履歴 → 3点リーダー → 領収書） |
| **宛名** | **購入者が自由に書き換えられる**（会社名を入れられる） |
| インボイス | **販売者がインボイス登録していれば**インボイスが発行される。未登録なら通常の領収書 |
| キャリア決済の上限 | ドコモ・au は**1回10,000円**／ソフトバンクは10万円 |

### ここが決定的

> **領収書は購入者が自分で出せて、宛名も自分で会社名に書き換えられる。**

つまり——

- **こちらは何もしなくていい。** 請求書も、領収書の郵送も、やり取りも不要
- 買う人は**その場で経費精算できる**
- **監督側の作業は、記事を置くだけ。** いまと完全に同じ

### ⚠️ ただし1つだけ注意

**9,800円にするなら、キャリア決済（ドコモ・au）の上限10,000円に収まる。** これは良い。
**1万円を超えると、ドコモ・au払いの人が買えなくなる。** 現場の人はキャリア決済を使う人が多い。

**→ 価格は9,800円が上限。** 技術的な理由がある。

## 算数

| | いまの個人向け | 会社の個人向け |
|---|---|---|
| 価格 | 1,480円 | **5,000〜9,800円** |
| 月5万円に必要な数 | **34本** | **6〜10本** |
| 買う動機 | 自分が受かりたい | **仕事が楽になる／経費で落ちる** |
| 財布 | **自腹** | **会社の経費**（または自腹でも許容できる額） |

> 📌 **自腹1,480円と、経費9,800円では、買うときの痛みが逆転する。**
> 経費なら「1万円以内」は、現場代理人クラスなら**判断1つで通る。**

## 買う人は誰か

**受検者ではない。現場を回している人。**

| | |
|---|---|
| 立場 | 現場代理人・主任技術者・工事主任・1人で現場を回している人 |
| 年齢 | 30〜50代 |
| 困りごと | **書類の山。何を出せばいいか分からない。新人に教える時間がない。差し戻される** |
| 判断基準 | **自分の時間が浮くか。怒られずに済むか。部下に渡せるか** |

**「勉強したい」ではなく「早く終わらせたい」人。** ここが今までの客層と違う。

# 商品案

## 🥇 1位：現場1つ分の書類セット（9,800円）

**いちばん筋がいい。**

### 何が入るか

| | 素材 |
|---|---|
| 安全書類の「誰が・いつ・誰に出すか」早見表 | 新規作成（既存3記事が土台） |
| 新規入場者教育の記録 ひな形＋記入例 | **既存記事** |
| 作業員名簿 ひな形＋記入例 | **既存記事** |
| KY活動記録 ひな形＋記入例 | **既存記事** |
| 施工計画書の目次14項目＋提出前チェックリスト | **既存記事（本日強化済み）** |
| 工事写真の撮り忘れ対処＋撮影計画の型 | **既存記事（本日強化済み）** |
| 差し戻されない書き方（NG集） | 新規 |

**既存資産の7割が、もうある。**

### なぜ9,800円が通るか

**書類1枚を作り直す手間が1時間として、時給換算で元が取れる。**
差し戻し1回を防げれば、それだけで回収できる。**この説明が成り立つ金額。**

## 🥈 2位：部下に資格を取らせたい人向け（9,800円）

**買う人は受検者本人ではなく、その上司。**

| | |
|---|---|
| 買う人 | 工事課長・所長・社長（中小） |
| 動機 | **経営事項審査。** 技術職員の資格が会社の点数になり、入札に響く |
| 悩み | **取らせたいが、取らせ方が分からない。3人受けさせて1人しか受からない** |

### 監督しか持っていない答え

| 悩み | 答え |
|---|---|
| 社員が「忙しくて勉強できない」と言う | **「帰ってからは手につかない」を認めたうえでの、休憩時間の方法** |
| 教材を買っても続かない | **いつ・どこで・何を の決め方** |
| 3人受けて1人しか受からない | **まさにそれを経験している。差は能力ではない** |

**資格学校は「うちの講座を受けさせてください」としか言えない。**

### 中身（案）

- 既存の合格パック（**そのまま**）
- **続けさせる仕組み**（[キット設計](kit-planner-redesign.md) の「いつ・どこで・何を」シート）
- **部下に渡す進め方**（いつ声をかけるか、何を聞くか）
- 進捗が見える1枚

⚠️ **経審の配点を根拠に使うなら、公開前に公式資料で必ず確認する**（年度改正あり）。

## ❌ やらないこと

| | 理由 |
|---|---|
| **会社と契約する形（請求書・稟議）** | 契約・営業・サポートが発生。**本業があるので回らない** |
| 様式テンプレ一式 | 元請ごとに様式が違う。「うちのと違う」で終わる |
| 社内研修・講師 | **時間を売ることになる。** スケールしない |
| 契約書のひな形 | 建設業法第19条。**専門家の領域** |

---

## 🔴 それでも確認が要ること（前より軽いが、ゼロではない）

| | いまと比べて |
|---|---|
| **副業規定** | **note販売という形は変わらない**ので、リスクはいまと同程度。ただし**金額が上がる**ので、確認はしておきたい |
| **インボイス登録** | **買う人が経費で落とすなら、インボイスを求められる可能性**がある。未登録でも通常の領収書は出るので**売れないわけではない**が、登録していれば有利 |

> ⚠️ **インボイスは、登録すると消費税の納税義務が生じる。** 税理士に相談してから。
> 📌 ただし**「インボイス未登録でも売れる」**（通常の領収書は発行される）。**登録待ちで止める必要はない。**

**前の「法人契約」案と違い、これは本業リスクが大きく下がる。**

## 正直な見通し

**月6〜10本売れれば5万円。** 達成可能な数字に見える。

ただし条件がある。

- **実務記事の読者を、いまの3〜5倍にする**（月150表示 → 月500〜750表示）
- **「早く終わらせたい人」に届く記事**を書く（いまの記事は「勉強したい人」向けに寄っている）

**試験系（過去問・パック）は引き続き柱。** これは第2の柱を作る話。
**試験期以外の谷（1〜3月・7〜9月）を埋める**のに、ちょうど合っている。
