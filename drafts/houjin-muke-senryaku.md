# 法人向けに売る｜戦略メモ

2026-11-06。監督の方針転換「**実務は個人に売るんじゃない、会社に売るんだ**」を受けて。

---

## 🔴 最初に：始める前に必ず片付けること

**ここを飛ばすと、本業を失いかねません。** 金額の話より先に書きます。

### ① 副業規定の確認（最重要・未確認のまま）

| | |
|---|---|
| いま | **note で個人向けに売っている**。金額は小さく、匿名性もある |
| 法人向けにすると | **請求書・契約書・屋号・振込**が発生する。**匿名では済まない** |

**同業（土木・造園）の会社に売る**ので、本業の勤務先の耳に入る可能性は、いまとは比べものになりません。

> ⚠️ **就業規則を読んでから**判断してください。「副業禁止」でなくても「**競業避止**」の条項があることが多く、**同業への営業はそこに当たる可能性**があります。
> 判断がつかない場合は、社労士など専門家に確認を。**私（Claude）が判断できる範囲を超えます。**

### ② インボイス（適格請求書）の登録

**法人は適格請求書を求めます。** 個人客なら不要でも、法人相手では「出せません」と言った時点で話が止まることがあります。

**→ 登録するかどうかは税理士に相談。** 登録すると消費税の納税義務が発生します。

### ③ 本業との利益相反

**監督の勤務先と、売る相手が競合する可能性**があります。
特に「資格取得支援」は、**他社の技術者を増やす＝勤務先の競争相手を強くする**という見方もできます。

### ④ 契約・サポートの責任

note の売り切りと違い、法人取引には**納期・問い合わせ対応・返金**がついてきます。
**監督には本業があります。** そこに耐えられる設計にしないと続きません。

## なぜ法人向けだと算数が変わるか

| | 個人向け | 法人向け |
|---|---|---|
| 1件あたり | **980〜1,480円** | **3〜10万円**（想定） |
| 必要な客数 | **月34人**で5万円 | **月1社**で足りる |
| 検索需要の制約 | **致命的**（実務書類は3か月200表示） | **致命的ではない** |

> 📌 **「実務書類のクエリが200表示しかない」は、法人向けなら問題にならない。**
> 個人向けは「大量×薄利」、法人向けは「少数×厚利」。**前提が違う。**

# 🥇 いちばん強い商材：書類ではなく「資格取得支援」

**これが本命だと思います。**

## なぜか：会社にとって資格は「コスト」ではなく「売上機会」だから

| | |
|---|---|
| **経営事項審査（経審）** | 技術職員の数と資格が**会社の点数**になる |
| 配点の例 | **1級国家資格者は最高クラス**（監理技術者講習を受けた1級は6点、その他の1級・技術士は5点、2級は2点、監理技術者補佐4点） |
| 何が起きるか | **点数が足りないと、入札に出られない** |
| 配置義務 | 主任技術者・監理技術者を置けないと、**その工事が受けられない** |

> ⚠️ 配点は年度ごとの改正があります。**提案書に数字を書く前に、国交省または都道府県の最新の審査基準で必ず確認すること。**
> （2025年度にも技術職員の加点に変更あり）

**つまり会社にとって、社員が1級を取ることは「福利厚生」ではなく「売上に直結する投資」です。** だから稟議が通ります。

## 会社の悩みと、監督が持っている答え

| 会社の悩み | 監督が持っているもの |
|---|---|
| 社員に資格を取らせたいが、**取らせ方が分からない** | **独学で3冠。全部自分でやった** |
| 社員が「忙しくて勉強できない」と言う | **「帰ってからは手につかない」を認めたうえでの、休憩時間の方法** |
| 会社が教材を買っても、**社員が続かない** | **いつ・どこで・何を の決め方。続かない理由の答え** |
| 3人受けさせても**1人しか受からない** | **まさにそれを経験している。差は能力ではなく、やり方と期限** |

**これは、他の教材屋が持っていない答えです。**

資格学校は「うちの講座を受けさせてください」としか言えません。
**監督は「現場の人間が、休憩時間だけでどう取ったか」を実体験で言えます。**

## 商品の形（案）

### 法人向け 合格支援パッケージ

| 中身 | 素材 |
|---|---|
| 合格パック **×受講人数分** | **既存商品そのまま** |
| 1,357問のクイズ | **既存。無料だが「使い方」をつける** |
| 過去問PDF（登録不要） | **既存** |
| **続けさせる仕組み**（いつ・どこで・何を のシート） | [kit-planner-redesign.md](kit-planner-redesign.md) の設計をそのまま使う |
| 進捗が分かるもの（担当者が見る） | 新規。1枚でよい |

**既存資産でほぼ作れます。** 新規制作は「続けさせる仕組み」と「進捗表」だけ。

### 価格の考え方

**人数ライセンスにする。** 1社あたり数万円。

⚠️ **質問対応は入れないか、強く限定する。** 監督には本業があります。
サポートを約束すると、**単価より先に時間が壊れます。**

# 🥉 やらないほうがいいもの

## 安全書類の様式テンプレ一式

**様式は元請ごとに違います。** 全建統一様式を使う現場もあれば、ゼネコン独自の様式もある。
**汎用品を作っても「うちの様式と違う」で終わります。**

→ **記入例と考え方の解説**としては価値がある（＝いまの無料記事のまま）。**テンプレ商品にはしない。**

## 社内研修・講師

**時間を売ることになります。** 監督には本業がある。**スケールしないし、続きません。**

# どうやって売るか（現実的な話）

**飛び込み営業はできません。** 本業があります。

### 唯一現実的なのは「待ち」の形

1. **ブログに「法人の方へ」のページを1枚置く**
   - 何ができるか／対象／おおよその費用感／問い合わせ先
   - **既存の問い合わせフォーム（/contact）につなぐ**
2. **実務記事・資格記事から、そのページに静かに導線を引く**
3. **問い合わせが来たら対応する**

> **月1社でいい**のだから、待ちで足ります。
> いま月1万人がサイトに来ています。そのうち**決裁権のある人が何人かは必ずいます。**

### ⚠️ ただし、順番を間違えないこと

**①の副業規定を確認するまでは、「法人の方へ」のページを公開してはいけません。**
公開した瞬間に、**勤務先が見つけられる状態**になります。

## 正直に言っておくこと

**法人向けは、当たれば大きいが、確実ではありません。**

- 問い合わせが**ゼロのまま**ということは十分あります
- 1件対応するのに、思ったより時間を取られます
- **本業のリスクは、金額に見合うのか**を考える必要があります

一方で、**いまの個人向け（月1.3万円）を10倍にするのは、アクセスを10倍にしないと無理**です。
**法人1社で、noteの月商を超えます。** 試す価値はあると思います。

**ただし①を先に。** そこだけは譲れません。
