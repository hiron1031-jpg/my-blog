## 問題2　工程表（穴埋め）

### 問題

建設工事に用いる工程表に関する文章中の（イ）〜（ホ）に当てはまる適切な語句を、下記から選び記入しなさい。

> (1) 横線式工程表には、バーチャートとガントチャートがあり、バーチャートは縦軸に部分工事をとり、横軸に必要な日数を棒線で記入した図表で、各工事の**（イ）**がわかりやすい。
> (2) ガントチャートは縦軸に部分工事をとり、横軸に各工事の**（ロ）**を棒線で記入した図表で、各工事の進捗状況がわかる。
> (3) **（ハ）**工程表は、工事内容を系統的に明確に、作業相互の関連や順序、施工時期等を的確に判断でき、**（ニ）**工事と部分工事の関連が明確に表現できる。また、**（ホ）**を求めることにより重点管理作業や工事完成日の予測ができる。

［語句］アクティビティ、安全性、休憩、掘削、クリティカルパス、グラフ式、工期、斜線式、晴天日、全体、鉄筋、出来高比率、ネットワーク式、費用、PERT

### 解答

| | 答え |
|---|---|
| （イ） | **工期** |
| （ロ） | **出来高比率** |
| （ハ） | **ネットワーク式** |
| （ニ） | **全体** |
| （ホ） | **クリティカルパス** |

### 解説

**バーチャートとガントチャートの違いが、この問題の軸です。** 名前が似ていて混同しやすいので、ここで決着をつけておきましょう。

| | 縦軸 | **横軸** | 何がわかるか |
|---|---|---|---|
| **バーチャート** | 部分工事 | **日数** | 各工事の**工期**と時期 |
| **ガントチャート** | 部分工事 | **達成度（%）** | 各工事の**進捗率** |

**横軸が「日数」ならバーチャート、「%」ならガントチャート。** これだけ覚えれば迷いません。

- **（イ）工期**：横軸が日数なので、棒の長さ＝その工事にかかる期間。つまり工期が読み取れます。「安全性」「費用」は工程表から読み取るものではありません。
- **（ロ）出来高比率**：ガントチャートの横軸は0〜100%の達成度。だから「進捗状況がわかる」と続きます。日数は読み取れないのが弱点です。

**（ハ）ネットワーク式**：「作業相互の関連や順序」という言葉がヒントです。作業同士を矢印でつないで前後関係を表すのはネットワーク式だけ。バーチャートやガントチャートは、作業が並んでいるだけで**関連が表現できません**。

**（ニ）全体**：「全体工事と部分工事の関連」。ネットワーク式は、どの部分工事が全体の工期に効くかが見える、という文脈です。

**（ホ）クリティカルパス**：**最も時間のかかる経路＝全体の工期を決める経路**です。ここが遅れると工事全体が遅れるので「重点管理作業」になり、ここの合計日数が「工事完成日」になります。

<CalloutBox type="point" title="現場での実感">
実務でいちばん使うのは**バーチャート**です。エクセルで作れて、誰が見てもわかる。ネットワーク式は試験には出ますが、中小規模の現場で日常的に使うことは多くありません。

ただし**工期が遅れたとき**、どの作業を優先して人を入れるか判断するには、クリティカルパスの考え方がそのまま役に立ちます。
</CalloutBox>

## 問題3　建設リサイクル法（記述）

### 問題

建設工事に係る資材の再資源化等に関する法律（建設リサイクル法）により定められている、特定建設資材である**コンクリート及び木材の再資源化後の材料名又は主な利用用途**を記述しなさい。

### 解答例

**コンクリート**

| 再資源化後の材料名 | 主な利用用途 |
|---|---|
| 再生クラッシャラン | 路盤材、埋戻し材、基礎材 |
| 再生粒度調整砕石 | 上層路盤材 |
| 再生コンクリート砂 | 埋戻し材、裏込め材 |

**木材**

| 再資源化後の材料名 | 主な利用用途 |
|---|---|
| 木質ボード（パーティクルボード等） | 建築用建材 |
| 木材チップ | 製紙原料、燃料（木質バイオマス発電） |
| 堆肥 | 緑農地還元 |

### 解説

**「材料名」か「用途」のどちらかを書けばよい**問題です。両方書く必要はありません。

特定建設資材は4つ（**コンクリート／コンクリート及び鉄から成る建設資材／木材／アスファルト・コンクリート**）。このうち今回はコンクリートと木材が問われました。

- **コンクリート塊** → 破砕して**再生砕石**になります。現場で「RC-40」と呼んでいるものがこれです。路盤材が一番多い使い道。
- **木材** → チップ化して、**ボード・紙・燃料・堆肥**のどれかになります。

> ⚠️ **「再資源化後」と書いてあることに注意してください。** 「コンクリート塊」「建設発生木材」と答えると、それは再資源化**前**の名前なので点になりません。

★**監督へ**：現場で実際に使っている呼び方（RC-40、再生砕石など）で補足を入れると、他の解説との差別化になります。言い回しの追加をお願いできますか。

## 問題4　コンクリートの養生（穴埋め）

### 問題

コンクリートの養生の目的及び方法に関する文章中の（イ）〜（ホ）に当てはまる適切な語句又は数値を、下記から選び記入しなさい。

> (1) コンクリートは打込み後の一定期間、**（イ）**に必要な湿潤状態及び温度に保ち、コンクリートが所定の品質を確保できるように養生しなければならない。
> (2) 湿潤養生の期間は、使用する**（ロ）**の種類や養生期間中の環境温度等に応じて、施工実績、信頼できるデータ、あるいは試験等により定める。例えば高炉セメントB種を使用し、日平均気温15℃以上の場合の湿潤養生期間の目安は**（ハ）**日以上とする。
> (3) コンクリートの湿潤養生期間は、日平均気温が低いほど**（ニ）**しなければならない。
> (4) コンクリートは、所定の強度が得られるまで、低温、高温、**（ホ）**な温度変化等による有害な影響を受けないように、必要に応じて養生時の温度の制御を行う。

［語句又は数値］急激、硬化、骨材、成長、セメント、鉄筋、同等に、鈍化、平坦、長く、短く、緩やか、2、3、7

### 解答

| | 答え |
|---|---|
| （イ） | **硬化** |
| （ロ） | **セメント** |
| （ハ） | **7** |
| （ニ） | **長く** |
| （ホ） | **急激** |

### 解説

**（ハ）の数値が唯一の暗記項目**です。ここだけは覚えるしかありません。

**湿潤養生期間の標準（日平均気温15℃以上）**

| セメントの種類 | 必要日数 |
|---|---|
| 早強ポルトランドセメント | **3日** |
| 普通ポルトランドセメント | **5日** |
| **混合セメントB種（高炉セメントB種など）** | **7日** |

**3・5・7**と覚えてください。早強が一番短く、混合セメントB種が一番長い。混合セメントは初期強度の出方がゆっくりなので、その分長く守ってやる必要がある、という理屈です。

- **（イ）硬化**：養生の目的は「セメントの水和反応を進めて硬化させること」。「成長」は生き物の話で、コンクリートには使いません。
- **（ロ）セメント**：直後に「高炉セメントB種を使用し」と続くので、ここはセメント。骨材の種類で養生期間は変わりません。
- **（ニ）長く**：気温が低いと水和反応が遅くなる → **長く養生する**。冬に型枠をいつまでも外せないのはこのためです。
- **（ホ）急激**：「低温、高温、急激な温度変化」。急に冷えると表面と内部で温度差ができ、**温度ひび割れ**の原因になります。

<CalloutBox type="warn" title="引っかけ選択肢に注意">
（ニ）には「**短く**」という逆の選択肢が用意されています。「気温が低い＝早く固まらないから長く」と、理屈で結びつけておけば迷いません。丸暗記だと逆を選びます。
</CalloutBox>

## 問題5　法面保護工（記述）

### 問題

法面保護工について①〜④から2つ選び、番号とその工法の**目的又は施工上の留意点**を記述しなさい。
（解答欄の（例）と同一内容は不可。また、それぞれの解答が同一内容は不可）

> ① 種子散布工　② 張芝工　③ モルタル・コンクリート吹付工　④ 現場打ちコンクリート枠工

### 解答例

**① 種子散布工**

| | |
|---|---|
| 目的 | 法面を植生で被覆し、**雨水による表面侵食を防止**するとともに、緑化により周辺景観と調和させる |
| 施工上の留意点 | **発芽・生育に適した時期に施工**する。散布前に法面の浮き石や有害物を取り除き、種子・肥料・ファイバーが均一になるよう散布する |

**② 張芝工**

| | |
|---|---|
| 目的 | 法面全面を芝で覆い、**施工直後から侵食防止効果**を得る |
| 施工上の留意点 | 芝と法面の間に**空隙ができないよう密着**させ、目串で固定する。施工後は活着するまで散水する |

**③ モルタル・コンクリート吹付工**

| | |
|---|---|
| 目的 | **風化・侵食しやすい岩や硬い土の法面**を被覆し、風化と表面崩落を防止する |
| 施工上の留意点 | **水抜き孔を設けて背面の水圧上昇を防ぐ**。施工前に浮き石・泥・草を除去し、金網を法面に密着させる |

**④ 現場打ちコンクリート枠工**

| | |
|---|---|
| 目的 | **法面の崩壊を抑止**し、枠内を植生等で保護する。すべり面が浅い法面の安定を図る |
| 施工上の留意点 | 枠が法面に**密着するよう不陸を整正**し、アンカーで固定する。枠内は植生工等で確実に処理する |

### 解説

**選ぶなら③と④が書きやすい**です。理由は、留意点が明確だからです。

- **③は「水抜き孔」**が定番の答え。吹付けで法面を覆うと、背面に溜まった水の逃げ場がなくなり、水圧で吹付け面が浮いて剥落します。これは現場でも実際に起きます。
- **④は「密着」と「アンカー」**。枠が浮いていたら、崩壊を抑える力が伝わりません。

①②の植生系は「侵食防止」「緑化」が目的で共通しているため、**2つとも植生系を選ぶと「同一内容」と判断される危険**があります。

<CalloutBox type="point" title="選び方のコツ">
**植生系（①②）から1つ、構造物系（③④）から1つ**選ぶのが安全です。目的がはっきり違うので、「同一内容は不可」の条件に引っかかりません。
</CalloutBox>

★**監督へ**：法面保護工の施工経験があれば、実際にやった工法の留意点を1つ足していただけると、解説の厚みが出ます。

## 問題6　盛土の材料及び施工（穴埋め）

### 問題

> (1) 盛土材料として利用する土には、**（イ）**強度が大きく、**（ロ）**が小さいもので、施工が容易なものを用いる。
> (2) 大型の発泡スチロールブロックを盛土材料や擁壁背面の裏込め材料として用いる**（ハ）**工法は、土と比較して軽量で扱いやすく工期短縮や完成後の沈下防止に有効である。
> (3) 盛土の施工で、基礎地盤が軟弱で地耐力が不足している場合は、必要に応じてその全部又は一部を良質な材料で施工する**（ニ）**工法等により、地盤を補強しなければならない。
> (4) 盛土の施工は、盛土材料を水平に敷くことと、均等に締め固めることが重要であり、敷均し厚さは、盛土の目的、盛土材料の**（ホ）**・土質、締固め機械と施工法及び、締固め度等の条件による。

［語句］圧縮性、拡散性、均一性、掘削置換、せん断、脱水、反力、比重、引張、曲げ、薬液注入、粒度、EPS、NATM、RCD

### 解答

| | 答え |
|---|---|
| （イ） | **せん断** |
| （ロ） | **圧縮性** |
| （ハ） | **EPS** |
| （ニ） | **掘削置換** |
| （ホ） | **粒度** |

### 解説

**（イ）（ロ）はセットで覚えてください。** 良い盛土材料の条件は、

> **せん断強度が大きく、圧縮性が小さい**

この一文がそのまま出題されています。土は引張やねじりではなく、**せん断で壊れる**ので「せん断強度」。そして**圧縮性が大きい＝後から沈む**ので、小さいほうが良いわけです。

**（ハ）EPS**：発泡スチロールの英語名（Expanded Poly-Styrene）。**EPS工法＝発泡スチロール工法**です。軽量盛土の代表格で、土の約1/100の重さ。軟弱地盤で沈下を避けたいときや、擁壁の裏込めで土圧を減らしたいときに使います。

> NATM＝トンネル、RCD＝ダムのコンクリート。**どちらも盛土とは無関係**なので、消去法でも選べます。

**（ニ）掘削置換**：軟弱な土を**掘って、良い土に置き換える**。言葉そのままです。「薬液注入」も地盤改良ですが、問題文に「良質な材料で施工する」とあるので、材料を入れ替える掘削置換が正解です。

**（ホ）粒度**：敷均し厚さを決める条件。**粒度＝粒の大きさの分布**です。粒が大きい材料は厚く敷けますが、細かい材料は薄く敷かないと締め固まりません。

<CalloutBox type="point" title="敷均し厚さの目安">
試験では数値も問われることがあります。**路体は1層の敷均し厚さ35〜45cm以下で締固め後30cm以下、路床は25〜30cm以下で締固め後20cm以下**。あわせて覚えておくと得です。
</CalloutBox>

## 問題7　コンクリートの品質確保（穴埋め）

### 問題

> (1) レディーミクストコンクリートの購入にあたっては、コンクリートの種類、**（イ）**強度、荷卸し地点でのスランプ、粗骨材の最大寸法、セメントの種類を生産者に指定しなければならない。
> (2) コンクリートの練混ぜから打ち終わるまでの時間は、外気温が25℃以下のときで**（ロ）**時間以内、25℃を超えるときで1.5時間以内を標準とする。
> (3) 鉄筋コンクリートで使用する鉄筋の加工は**（ハ）**で行い、一度曲げた鉄筋の曲戻しは行わない。また、型枠は外力やコンクリートの**（ニ）**に対し、十分な強度と剛性を持っていなければならない。
> (4) コンクリート構造物の出来形は、位置及び形状寸法が、発注者の定める**（ホ）**を満足しなければならない。

［語句又は数値］許容差、高温、工期、材齢、収縮、常温、側圧、低温、配合、引張、費用、呼び、2、2.5、3

### 解答

| | 答え |
|---|---|
| （イ） | **呼び** |
| （ロ） | **2** |
| （ハ） | **常温** |
| （ニ） | **側圧** |
| （ホ） | **許容差** |

### 解説

**（ロ）の時間制限は必ず覚えてください。** 毎年どこかで問われます。

| 外気温 | 練混ぜ〜打ち終わり |
|---|---|
| **25℃以下** | **2時間以内** |
| **25℃を超える** | **1.5時間以内** |

暑いほど短い。セメントの水和が早く進んでしまうからです。**「25℃で2時間と1.5時間」**とセットで暗記してください。

<CalloutBox type="warn" title="「打重ね時間」と混同しないでください">
コンクリートの時間制限には、**よく似た別の数値**があります。ここを取り違える人が非常に多いです。

| | 25℃以下 | 25℃を超える |
|---|---|---|
| **練混ぜ〜打ち終わり**（今回の問題） | **2時間** | **1.5時間** |
| **打重ね時間間隔**（別の規定） | 2.5時間 | 2時間 |

**「2時間」がどちらにも出てくる**のが混乱のもとです。

- **練混ぜ〜打ち終わり**＝工場で練ってから、打設を終えるまでの全体の時間
- **打重ね時間間隔**＝下の層を打ってから、上の層を打つまでの時間（コールドジョイント防止）

**今回問われているのは前者**です。問題文に「練混ぜから打ち終わるまで」と明記されているので、落ち着いて読めば間違いません。
</CalloutBox>

**（イ）呼び**：レディーミクストコンクリートでは「**呼び強度**」と言います。設計基準強度に割増しをした、発注時に指定する強度のことです。「18-8-25-N」のような表記の最初の数字がこれです。

**（ハ）常温**：鉄筋は**常温で加工**するのが原則。加熱して曲げると材質が変わってしまいます。また「一度曲げた鉄筋の曲戻しは行わない」のは、曲げ戻すと**その部分が脆くなる**ためです。

**（ニ）側圧**：型枠には、まだ固まっていないコンクリートが**横に押す力**がかかります。これが側圧。打上がり速度が速いほど、温度が低いほど大きくなります。型枠が「はらむ」事故はこれが原因です。

**（ホ）許容差**：出来形管理の話。設計寸法に対して、どこまでのズレを許すかの基準です。

# 選択問題（2）　問題8・問題9から1問

## 問題8　車両系建設機械の安全対策（記述）

### 問題

下図は車両系建設機械で掘削・積込の作業を行っている現場状況である。この現場において、車両系建設機械を用いて作業を行う場合に、**労働安全衛生規則に定められている事業者が実施すべき安全対策を2つ**記述しなさい。（解答欄の（例）と同一内容は不可）

> 📷 **ここに図を入れてください** → `drafts/note-images/R8_2doboku_mondai8_zu.png`
>
> （図の内容：切土法面に囲まれた掘削現場。バックホウが掘削してダンプトラックに積み込んでおり、**その間に作業員が1人立って合図をしている**。バックホウは敷鉄板の上に設置されている）

### 解答例

**この5つから2つ選んでください。**

| # | 安全対策 | 根拠（労働安全衛生規則） |
|---|---|---|
| 1 | **運転者以外の労働者を、機械の接触するおそれのある箇所に立ち入らせない。** やむを得ない場合は誘導者を配置し、その合図に従って運転させる | 第158条 |
| 2 | 作業箇所の**地形・地質を事前に調査**し、その結果にもとづいた**作業計画を定めて、計画に従って作業**を行う | 第154条・第155条 |
| 3 | **転倒・転落を防止**するため、運行経路について**路肩の崩壊防止・地盤の不同沈下防止・必要な幅員の保持**を行う | 第157条 |
| 4 | 運転者が運転位置を離れるときは、**バケットを地上に下ろし、原動機を止め、走行ブレーキをかける** | 第160条 |
| 5 | **主たる用途以外の用途に使用しない**（バケットでの荷のつり上げ、労働者の昇降等を行わない） | 第164条 |

### 解説

**図を見て、何が危ないかを言葉にするのがコツ**です。

図から読み取れるのは次の3点です。

| 図に描かれていること | そこから見える危険 |
|---|---|
| バックホウが掘削し、ダンプに積み込んでいる | **旋回するバケットと車両の接触** |
| **作業員が1人、バックホウとダンプの間に立って合図している** | **旋回範囲内への立入り・接触** |
| 切土法面に囲まれた狭い場所。バックホウは敷鉄板の上 | **法面の崩壊・機械の転倒** |

一番の危険は明らかです。

> **旋回するバックホウと、すぐそばに立っている作業員の接触**

だから**1番（接触防止・誘導者の配置）は、ほぼ確実に点になります。** まずこれを書いてください。

<CalloutBox type="point" title="図に合図者が描かれていても、1番を書いてよい理由">
「すでに誘導者がいるじゃないか」と思うかもしれません。でも規則が求めているのは、

> **接触のおそれのある箇所に労働者を立ち入らせないこと。やむを得ず立ち入らせるときは誘導者を置き、その合図に従わせること**

の**両方**です。図の状況は後者にあたるので、「誘導者を配置し、運転者はその合図に従って運転する」と書けば、図とも矛盾しません。
</CalloutBox>

2つ目は、同じ「接触」系ではなく**別の観点**から選ぶのが安全です。図は**切土法面に囲まれた狭い掘削場所**なので、**3番（路肩の崩壊防止・転倒防止）**が自然につながります。

<CalloutBox type="warn" title="書いてはいけない答え">
- **「ヘルメットを着用させる」「安全帯を使用させる」** → 車両系建設機械の規定ではなく、保護具一般の話。設問が「車両系建設機械を用いて作業を行う場合」と限定しているので外れます。
- **「作業員が注意する」** → 設問は**事業者が実施すべき**対策を聞いています。作業員の心がけは答えになりません。
</CalloutBox>

★**監督へ**：この問題は図の読み取りが肝です。実際に図を見て「自分ならまずこれを言う」という順番が違っていたら教えてください。

## 問題9　騒音防止対策（記述）

### 問題

ブルドーザ又はバックホウを用いて行う建設工事における**具体的な騒音防止対策を5つ**記述しなさい。

### 解答例

| # | 騒音防止対策 |
|---|---|
| 1 | **低騒音型・超低騒音型の建設機械**（国土交通省指定）を使用する |
| 2 | 機械の**整備・点検を十分に行い**、消音器の損傷やボルトの緩みによる異音を防ぐ |
| 3 | **無用な空ふかしや高回転での運転を避け**、不要なアイドリングを停止する |
| 4 | **作業場所の周囲に仮囲い・防音シート・防音パネル**を設置し、音源を遮蔽する |
| 5 | **作業時間帯を配慮**し、早朝・夜間・休日の作業を避けて住民の生活時間を乱さない |
| 6 | 機械の**稼働台数を減らす・集中させない**よう作業計画を立て、ピーク時の騒音を下げる |
| 7 | **運搬路を選定**し、住宅地を避ける。走行速度を落として走行騒音を抑える |

**上から5つ書けば十分です。**

### 解説

**5つ書かせる問題は「観点を散らす」のがコツ**です。同じ系統ばかり並べると「同一内容」とみなされる危険があります。

観点は大きく4つに分かれます。

| 観点 | 具体例 |
|---|---|
| **機械そのもの** | 低騒音型を使う（1）、整備する（2） |
| **使い方** | 空ふかし・アイドリング停止（3）、速度を落とす（7） |
| **音を遮る** | 防音シート・仮囲い（4） |
| **時間と配置** | 作業時間帯（5）、台数を分散（6） |

**この4観点から満遍なく選べば、同一内容になりません。**

<CalloutBox type="point" title="一番確実なのは「低騒音型建設機械」">
国土交通省が指定している**低騒音型建設機械**は、騒音対策の筆頭として必ず挙がります。1つ目はこれを書いてください。

実務でも、市街地の工事では発注図書で低騒音型の使用が指定されていることが多いです。
</CalloutBox>

★**監督へ**：騒音でクレームを受けた経験や、実際にやった対策があれば1つ入れたいです。「教科書どおり」ではない具体例が入ると、この記事の価値が上がります。
