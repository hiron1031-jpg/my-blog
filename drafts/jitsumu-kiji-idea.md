## 評価の物差し

| 項目 | 見るところ |
|---|---|
| **① 義務** | 法令の義務か／契約（仕様書）か／慣習か |
| **② 面倒さ** | 作るのに時間がかかるか。様式が要るか |
| **③ 恐怖** | 間違えるとどうなるか（罰則・不合格・やり直し） |
| **④ 読者適合** | うちの読者＝**作業員〜若手監督**に当たるか |
| **⑤ 需要の証拠** | GSCに痕跡があるか。**ここが一番大事** |
| **⑥ 安全性** | うちが書いて危なくないか |

> 📌 **⑤が無いものは、どれだけ①〜③が良くても後回し。**

## 1. 安全書類（グリーンファイル）の「誰が・いつ・誰に出すか」早見表

**監督の提案にはなかったが、これが一番筋がいいと思う。**

| | |
|---|---|
| ① 義務 | 書類ごとに違う（法令・ガイドライン・現場運用が混在） |
| ② 面倒さ | ◎ **何を出せばいいか分からないのが最大の困りごと** |
| ③ 恐怖 | ◎ 出し忘れると現場に入れない／協力会社に迷惑 |
| ④ 読者適合 | ◎ **下請の職長・若手監督どんぴしゃ** |
| ⑤ 需要の証拠 | ○ 新規入場者教育が17日で84表示。作業員名簿・KYも公開済み |
| ⑥ 安全性 | ○ 「会社・元請の様式に従ってください」で逃げ道がある |

**なぜ良いか：すでに3本書いてある。** 新規入場者教育・作業員名簿・KY活動記録。
**この3本を束ねるハブ**になる。記事クラスタの「束ね役」が無いのが今のサイトの弱点でもある。

**中身の案**

| 書類 | 誰が作る | 誰に出す | いつ |
|---|---|---|---|
| 再下請負通知書 | 二次以降の下請 | 元請 | 契約したら |
| 作業員名簿 | 下請 | 元請 | 入場前 |
| 新規入場者教育の記録 | 下請（元請が実施） | 元請 | 入場当日 |
| 持込機械等使用届 | 持ち込む会社 | 元請 | 持ち込む前 |
| 有資格者一覧 | 下請 | 元請 | 入場前 |

> ⚠️ **様式は元請・会社によって違う。** そこを最初に明記する。

## 2. 施工計画書の「目次（インデックス）」＋提出前チェックリスト

**監督の提案。これは良い。**

| | |
|---|---|
| ① 義務 | 契約（公共工事の共通仕様書で提出を求められる）。**法令義務ではない** |
| ② 面倒さ | ◎ **目次を作るのが一番面倒。** 何を書けばいいか分からない |
| ③ 恐怖 | ○ 差し戻されるとやり直し |
| ④ 読者適合 | ◎ **「新人が最初に任される書類」**（既存記事にそう書いてある） |
| ⑤ 需要の証拠 | △ **「施工計画書 チェックリスト 国交省」が実測2表示・順位5.5**。痕跡はある |
| ⑥ 安全性 | ◎ 危険なし |

⚠️ **弱点：工種ごとに中身が違う。** 汎用の目次は薄くなる。
→ **土木の一般的な工種に絞る**（道路・河川・舗装）ほうがいい。

**既存記事 `sekou-keikakusho` は7表示・順位7.4・クリック0。**
順位は取れているのにクリックが0＝**タイトルが検索語と合っていない**。
「施工計画書 **目次**」「施工計画書 **書き方**」「施工計画書 **チェックリスト**」を入れて測る。

## 3. 産業廃棄物（マニフェスト）

**監督の提案。条件はそろっている。ただし危ない。**

| | |
|---|---|
| ① 義務 | ◎ **廃棄物処理法 第12条の3。明確な法令義務** |
| ② 面倒さ | ◎ 交付・回収・照合・**5年保存**・**毎年6/30までに報告書** |
| ③ 恐怖 | ◎ **罰則あり**（第27条の2：1年以下の拘禁刑または100万円以下の罰金） |
| ④ 読者適合 | ◎ 現場監督が実際に扱う |
| ⑤ 需要の証拠 | ❌ **うちのGSCには1件も無い**（本文で触れている記事が2本あるだけ） |
| ⑥ 安全性 | ⚠️ **危ない** |

### ⚠️ 危ない理由

**誰が「排出事業者」になるかは、契約形態で変わる。**
建設工事では原則として元請が排出事業者だが、**断定して書くと間違いになる場面がある。**

> 監督は行政書士でも産廃の専門家でもない。
> **「最終的には工事場所を管轄する都道府県・政令市に確認してください」を必ず書く。**

### それでも良いところ

**「毎年6月30日まで」という期限がある。**
年1回必ず来る＝**実行意図（合図ベース）と相性がいい。**
**4〜6月に書けば、毎年その時期に読まれる記事**になる。

**→ 書くなら2027年4月。いまではない。**

# ❌ やらないほうがいいもの

## 7. 契約書の作り方・テンプレート配布

**これは勧めない。**

理由：

1. **建設工事請負契約は建設業法第19条で記載事項が法定。** 間違えると法的トラブルに直結する
2. **監督は行政書士ではない。** 解説記事は問題ないが、**ひな形を配って「これで契約できます」は危ない**
3. 中身を間違えたときの影響が、他の書類と比べて桁違いに大きい

> **ここは「専門家に相談を」と書くべき領域。**
> どうしても触れるなら「**建設業法第19条でこういう項目が必要と決まっています**」と**紹介だけ**にとどめる。

## ⚠️ 全体に関わる、正直な話

**実務書類は、試験系と比べて桁が2つ小さい。**

| | 3か月の表示 |
|---|---|
| 「2級土木施工管理技士 過去問」1クエリ | **4,561** |
| 実務書類のクエリ全部 | **200未満** |

**実務記事は「収益の柱」にはならない。**
やる意味は別にある。

1. **試験期以外（1〜3月・7〜9月）のアクセスを埋める**。試験系は季節で消える
2. **読者の滞在時間が長い**（役に立つ道具なので）
3. **監督にしか書けない**（現場をやった人の書類の話）

**柱はあくまで過去問とパック。** 実務記事は「谷を埋める」位置づけで進める。
