## 監督の疑問への答え（条文で確認済み／未確認を明記）

### ✅ 「建設業許可証とかいるんだっけ？」

**法令上、施工体制台帳の添付書類に「許可証の写し」は入っていない。**

施行規則第14条の2第2項の添付書類は4つだけ：
1. 請負契約・下請契約の**契約書面の写し**
2. **主任技術者／監理技術者の資格を証する書面＋雇用を証する書面**
3. 監理技術者補佐を置くときは同様の2点
4. 第2号トの者を置くときは同様の2点

**ただし** 台帳の記載事項には「**下請負人の許可番号と許可を受けた建設業の種類**」がある（第14条の2第1項第三号ロ）。
→ **元請は許可を確認しないと台帳が書けない。だから実務では「許可証の写しをください」と言われる。**

**記憶が曖昧になるのは当然。「法令の義務」と「元請が実務で求めるもの」が違うから。**
📌 **この区別こそが、この記事の価値。**

### ✅ 「技術者の資格証は忘れがち」

**これは法令上の添付書類そのもの**（第14条の2第2項第二号）。
しかも**資格証だけでは足りない**。「**雇用期間を特に限定することなく雇用されている者であることを証する書面**」もセット。
専任の監理技術者のときは「**監理技術者資格者証の写しに限る**」と条文で限定されている。

→ **忘れやすい理由がある。「2点セット」だと知られていないから。**

### ✅ 「主任技術者の兼務」→ 条文で確認完了（2026-11-12）

**順番に見ていけば答えが出る。4段階ある。**

#### 第1段階：そもそも「専任」が要るのか（令第27条第1項）

次の**両方**に当てはまるときだけ専任が必要。

| 条件 | 中身 |
|---|---|
| **施設の種類** | 国・地方公共団体が注文者の施設／学校・病院・事務所・共同住宅・工場・倉庫・ホテル・店舗（市場・百貨店）・集会場 など（条文に列挙） |
| **金額** | **工事1件の請負代金が4,500万円以上**（建築一式は**9,000万円**以上） |

→ **これに当たらなければ、そもそも専任不要＝兼務できる。** ここを知らずに悩んでいる人が多いはず。

#### 第2段階：専任が要る場合の例外（法第26条第3項ただし書）

| 号 | 条件 |
|---|---|
| **一号** | イ **請負代金が1億円未満**（建築一式2億円未満／令第28条）＋ ロ 現場間の移動時間等が省令の要件に適合 ＋ ハ 情報通信技術で職務を行う措置を講じる |
| **二号** | **監理技術者補佐**を専任で置く（このとき監理技術者は兼務可） |

#### 第3段階：兼務できても **現場は2つまで**（法第26条第4項・令第30条）

> 令第30条「法第二十六条第四項の政令で定める数は、**二**とする。」

#### 第4段階：「密接な関係のある工事」の特例（令第27条第2項）

> 密接な関係のある**二以上**の建設工事を**同一の建設業者**が**同一の場所又は近接した場所**において施工するものについては、**同一の専任の主任技術者**がこれらを管理することができる。

### ⭐ 下請にとって一番大きいのはこれ（法第26条の3・令第31条）

**特定専門工事なら、下請は主任技術者を置かなくてよくなる。**

| 条件 | 中身 |
|---|---|
| 工事の種類 | **型枠**（大工工事・とび土工のうちコンクリート打設用型枠の組立て）または **鉄筋工事**（令第31条第1項） |
| 金額 | 元請が結んだ**下請総額が4,500万円未満**（令第31条第2項） |
| 手続 | **元請と下請の書面による合意**（法第26条の3第3項） |
| 除外 | 元請が発注者から直接請け負い、下請総額が監理技術者を要する金額以上のものは対象外 |

→ 合意があれば**元請の主任技術者が下請の職務も兼ねる**。**その下請は主任技術者を置かなくてよい**（法第26条の3第1項後段）。

📌 **監督の「兼務で悩む」は、この4段階＋特定専門工事を知らないから。記事の目玉になる。**

## 🎯 2026-11-13 確認：様式は法令で決まっていない（C案の根拠）

監督の疑問「様式は公式のがあるんだっけ？任意の様式でいいのか？でも様式は違うけど書く内容は同じだよね」
→ **条文で確認した結果、監督の読みが正しい。**

| 書類 | 条文 | 様式の定め |
|---|---|---|
| **施工体制台帳** | 施行規則 第14条の2 | **無し**（条文に「様式」の語が出てこない。記載事項のみ列挙） |
| **再下請負通知書** | 施行規則 第14条の4 | **無し**（同上） |
| **施工体系図** | 施行規則 第14条の6 | **無し**。「…**系統的に表示して作成**しておかなければならない」＝表示すべき内容だけ |

→ **法令が決めているのは「何を書くか」であって「どの紙に書くか」ではない。**
→ だから元請ごとに様式が違う。**でも書く中身は全国どこでも同じ。**

### 📌 これが C案（会社情報を1回入れたら各書類に反映される）の根拠になる

**中身が法定で共通だから、入れ直す必要がない。** 商品説明にそのまま書ける主張。

### おまけ：「備え置く期間」と「保存する期間」は別物（施行規則 第14条の7 ほか）

> 施工体制台帳の**備置き**及び施工体系図の**掲示**は、**建設工事の目的物の引渡しをするまで**
> （請負契約に基づく債権債務が消滅した場合は、その消滅するまで）行わなければならない

| | 期間 |
|---|---|
| **現場に備え置く／掲示する** | **引渡しまで** |
| **保存する**（施工体制台帳） | 引渡しから**5年**（住宅新築は10年） |
| **保存する**（施工体系図） | 引渡しから**10年** |

**3つとも期間が違う。** ここを混同している人は多いはず。

### 前に❌にした経緯

| | |
