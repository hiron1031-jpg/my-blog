### なぜこの形か

1. **合格パックで実証済みの型**（単品2,280円 → パック1,480円。売上の75〜90%がパック）
2. **単品が検索の入口になる。** 「作業員名簿 書き方」で来た人がその単品を見て、セットに上がる
3. **試験系と違ってクラスタ重複にならない。** 書類ごとに検索語が別なので、Googleに嫌われにくい
4. **セット限定の2点があるから、セットを選ぶ理由が立つ**（＝キットと同じ役割）

### 単品を1,980円にする理由

- 980円だと、単品合計が5,880円になり **セット9,800円のほうが高くなって成立しない**
- 買う人は受検者ではなく**仕事中の人**。書類1枚の作り直し1時間ぶんと考えれば通る額

> note の上限は50,000円。ただし**ドコモ/auのキャリア決済は1回10,000円まで**なので
> 実質上限は9,800円。セット価格はこれに合わせてある。

## 🔴 先に片づけること（監督）

### ① 副業の社内規定

すでに note で販売しているが、**金額が上がると目立つ**。
**就業規則の副業条項を、自分で読んで確認してほしい。** ここは私が代われない。

### ② インボイス → **登録しない。これで進める**（2026-11-12 決定）

**監督は未登録。登録しないまま進める。**

| | |
|---|---|
| 登録すると | **売上1,000万円以下でも消費税の納税義務が発生する。** 手取りが減る |
| 登録しないと | 買った会社が消費税分（9,800円なら約890円）を控除できない |
| 実害 | **890円のために買うのをやめる会社は、まず無い** |

**対応：販売ページに「適格請求書（インボイス）は発行できません」と正直に書く。**
領収書そのものは note で購入者が自分で発行でき、宛名も変更できる（11/6に公式ヘルプで確認済み）。

> ⚠️ 税務は専門外のため断定しない。少額取引の特例などもあるが、適用は会社ごとに違う。
> 気になれば税務署に電話で確認できる（無料）。**進めるのを止める理由にはならない。**

**なぜ今まで問題にならなかったか**：これまでの客は受検者＝**自腹**。経費精算が起きないので無関係だった。
今回は「会社の経費で」を売り文句に使う計画だったため論点になった。
→ **売り文句から「経費で落とせる」を外せば、論点ごと消える。**

## 正直な見通し

**月1万円前後**が現実的な線。いまの月商（13,740円）が**倍になるかどうか**。

ただし、この商品の価値はそこではない。

| | |
|---|---|
| 試験系 | **年に数回しか売れない**（試験日に張り付く） |
| **実務系** | **毎月同じだけ売れる**（書類は毎月発生する） |

**閑散期（7〜8月）に売上がゼロにならない柱**を作るのが本当の目的。
