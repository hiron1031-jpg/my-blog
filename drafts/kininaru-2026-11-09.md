## ② 暗記シートの単体商品化／クイズの商品化

### 暗記シートについて

**監督の読みは正しいと思う。** 理由：

- いま暗記シートは、キット4ページのうち**1〜2ページしかない**
- 「問われ方 → 即答すべき語句」の形は、**他社がやっていない**
- 紙1枚で完結するので、**現場の休憩10分で使える**＝うちの読者の生活に合っている

#### ただし、確認が要ること

| | |
|---|---|
| **「商品は分けない」決定（2026-10-29）と矛盾しないか** | 同じ試験の客を2つに割るのはNG。**でも一次だけの客は別**（下記） |
| **いまパックは「二次」中心** | 一次だけ受ける人に**売るものが無い**。ここが空いている |
| 一次の受検者数 | 二次より多い（一次合格 → 翌年二次の人がいる） |

**→ 分けるのではなく「一次向けの暗記シート」という新しい客層をつくる案なら、矛盾しない。**

#### 決める前に測ること

- GSCで「◯◯ 一次 暗記」「◯◯ 覚え方」「◯◯ 語呂合わせ」系の検索があるか
- 一次だけの記事（zouen-2kyu-hinshutu 等）の表示数・滞在時間
- 競合（どぼくじら等）が暗記系を売っているか

#### 🔴 クイズを有料化するのは反対（現時点）

理由：

1. **クイズは集客装置。** 無料だから使われている。有料化したら346人が消える

3. **滞在3分05秒は「売り場」としての価値。** 売るなら**クイズの中で売る**ほうが効く

## ③ 試験がない時期の収益化

### まず、本当に「無い時期」はいつか

| 月 | 何がある |
|---|---|
| 1月 | 1級土木 二次 合格発表（R9/1/8）／2級造園 一次 発表（R9/1/5）／**申込準備** |
| 2〜3月 | 2級土木 二次 発表（R9/2/3）／2級造園・1級造園 発表（R9/3/3）／**申込** |
| 4〜5月 | 勉強開始期 |
| **7〜8月** | **ここが本当の閑散期** |
| 9〜12月 | 試験ラッシュ |

**→ 丸ごと空くのは7〜8月だけ。1〜4月は「発表 → 落ちた人 → 来年へ」「申込」「参考書」の需要がある。**

### 案の評価

#### ⭕ 実務系の書類ツール（本命）

- **試験と無関係に、毎日発生する**
- 新規入場者教育の記事＝公開10日で51表示（まだ伸びる）
- 会社の経費で買える（note 9,800円まで＝キャリア決済の上限）
- 調査済み：[[kouji-shorui-chosa]] [[jitsumu-kiji-idea]] [[houjin-muke-senryaku]]

**→ すでに下調べがある。閑散期の柱はこれ。**

#### ⭕ 転職系（ただし入口が足りない）

- ビルドジョブ 13,534円・確定率51.85％・**期待値 約7,017円/件**
- でも転職体験記は**17人しか読んでいない**（第1回）
- **商品の問題ではなく、流入の問題。** ツールを作っても読む人がいない

**→ 「転職プランナー」より先に、転職の検索需要を取る記事が要る。**

#### ⚠️ 職人の家計管理 — 私は反対です

| | |
|---|---|
| 読者が違う | 土木のトリセツの読者は「資格・実務」。家計は別の悩み |
| **権威がない** | 監督は3冠の施工管理技士。**家計の専門家ではない** |
| 競合が強い | 家計はFP・銀行・大手メディアの激戦区。勝てない |
| サイトの軸がぶれる | 「資格のサイト」が家計を語ると、信用が薄まる |

**ただし、土俵の中にある金の話はある：**

- 「資格手当はいくら？会社で3,000円と5,000円」← すでに記事あり
- 「2級と1級で手取りはどう変わるか」

**→ 家計そのものではなく「資格と金」。これなら監督が一番書ける。**
