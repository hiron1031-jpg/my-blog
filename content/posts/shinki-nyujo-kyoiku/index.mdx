「新規入場者教育の記録を作れと言われたが、**何を書けばいいのか分からない**」
「様式は自分で作っていいのか」
「教育で**何を話せばいいのか**が、そもそも分からない」

現場に人が入るたびに発生する作業なのに、**やり方を教わる機会がほとんどない**書類です。

この記事では、**記録に何を書くか**を実務の順番でまとめます。**空欄のひな形と架空の記入例**も置いてあるので、そのまま写して使ってください。

<CalloutBox type="target">
- 初めて新規入場者教育の記録を作る新人監督
- 様式をどれにすればいいか分からない人
- 教育で何を話せばいいか迷っている人
</CalloutBox>

<CalloutBox type="conclusion" title="この記事の結論">
- 様式は**まず元請に確認**。指定がなければ**全建統一様式第7号**が業界標準
- 教える中身は**労働安全衛生規則第35条の8項目＋その現場固有のこと**
- 記録で一番見られるのは**「実施日が入場日より前か」**
- **「安全に配慮した」では意味がない。** 場所と物を特定して書く
</CalloutBox>

## まず：様式は自分で作らなくていい

ここで時間を使う人が多いので、最初に書きます。

| 順番 | 確認すること |
|---|---|
| **1** | **元請の指定様式があるか**（あれば必ずそれを使う。これが最優先） |
| 2 | 会社に既存のひな形があるか |
| 3 | 無ければ **全建統一様式第7号「新規入場時等教育実施報告書」** |

**全建統一様式**は全国建設業協会がまとめた安全書類の標準セットで、建設業では広く使われています。第7号がこの教育の報告書にあたります。

ExcelやPDFの様式は複数のサイトが無料で配布しているので、**ゼロから作る必要はありません。**

<CalloutBox type="warn" title="独自様式を作る前に、必ず元請へ確認を">
元請が様式を指定している現場で独自の書式を出すと、**作り直しになります。**<br /><br />
「新規入場者教育の様式は、御社の指定がありますか」——着手前にこの一言を聞くだけで防げます。
</CalloutBox>

## なぜこの記録が必要なのか

**「新規入場者教育」は、実は法令上の名称ではありません。** 実務でそう呼ばれているだけです。

背景にあるのは、この2つです。

| 根拠 | 中身 |
|---|---|
| **労働安全衛生法 第59条**（具体項目は**労働安全衛生規則 第35条**） | 作業員を雇う事業者に、雇入れ時・作業内容変更時の**安全衛生教育の実施義務** |
| **労働安全衛生規則 第642条の3** | 元方事業者には、関係請負人が行う教育への**指導・援助**の義務 |

つまり**教育の実施義務は、その作業員を雇っている会社（下請）にあります。** 元請は、それが行われるよう場所や資料を提供して援助する立場です。

実務では、**その現場に初めて入る人へ、上の教育と現場固有のルールをまとめて行う場**として定着しました。それが新規入場者教育です。

<CalloutBox type="point" title="記録の保存期間について">
**特別教育**（安衛則第38条）には記録を**3年間保存**する定めがありますが、**雇入れ時教育・新規入場者教育の記録そのものの保存期間は、法令に明文の定めがない場合があります。**<br /><br />
ただし実務では、元請や発注者が保存を求めることがほとんどです。**どの記録をいつまで残すかは、元請の指示と、所轄の労働基準監督署への確認で決めてください。**
</CalloutBox>

## 何を教えるか

### ① 労働安全衛生規則 第35条の8項目

これは法令で決まっています。

1. 機械等、原材料等の**危険性・有害性**と、その取扱い方法
2. **安全装置・有害物抑制装置・保護具**の性能と取扱い方法
3. **作業手順**
4. **作業開始時の点検**
5. その業務で発生するおそれのある**疾病の原因と予防**
6. **整理・整頓・清潔**の保持
7. **事故時等の応急措置と退避**
8. その他、安全衛生のために必要な事項

### ② その現場だけのこと ← **ここが本番です**

8項目は、どの現場でも同じことを話せてしまいます。**本当に事故を防ぐのは、こちらです。**

| 項目 | 具体的に話すこと |
|---|---|
| **立入禁止区域・危険箇所** | 場所を特定して。「法面上部」「仮設道路の交差部」など |
| **重機の作業範囲と動線** | 何がどこで動くか。旋回範囲、誘導員の位置 |
| 保護具の着用基準 | どの作業でどこまで要るか（墜落制止用器具を使う場所） |
| **緊急時の連絡体制** | 第一報は誰か。連絡先はどこに貼ってあるか |
| **避難経路・一時集合場所** | 口で言うだけでなく、**実際に歩いて見せる** |
| 最寄りの医療機関 | 名前と、現場からの所要時間 |
| 現場のルール | 作業時間・休憩・喫煙場所・駐車場 |
| 季節対策 | 夏は熱中症、冬は凍結と防寒 |
| 廃棄物の分別 | どこに何を置くか |

<CalloutBox type="point" title="避難経路は「歩かせる」">
紙の上で説明しても、いざというときに動けません。**教育の最後に、集合場所まで実際に歩いてもらう**のが一番効きます。<br /><br />
5分で終わりますし、**歩いた人は覚えています。**
</CalloutBox>

## 提出前のチェックリスト

### 記入漏れ

- [ ] **実施年月日が、その人の入場日より前か同日**になっているか（**入場後の日付になっていないか**）
- [ ] 受講者全員の署名があるか（代筆になっていないか）
- [ ] 教育実施者の氏名・所属・役職が書かれているか
- [ ] 必要な資格・免許の欄が、**実際にやらせる作業と合っているか**
- [ ] 確認欄が空欄のまま残っていないか
- [ ] 現場固有の項目で、**その現場に該当するものだけにチェックが入っているか**（ひな形のまま全部チェックになっていないか）

### 不適切な表現

- [ ] 「安全に配慮した」「十分説明した」など、**何をしたか分からない書き方**になっていないか
- [ ] 危険箇所が「現場内」など漠然としていないか
- [ ] **「安全帯」と書いていないか**（現在の法令用語は**要求性能墜落制止用器具**）
- [ ] 実施していない項目にチェックが入っていないか
- [ ] 実施時刻が実態とかけ離れていないか（**10分で全項目を終えた**等）

### 記録の扱い

- [ ] 生年月日・住所など、**必要以上の個人情報を書いていないか**
- [ ] 保管場所と保管期間が決まっているか
- [ ] **元請の指定様式**がある場合、そちらを使っているか

## よくある失敗

### ① 実施日が、入場日より後になっている

**一番多い指摘です。** 「先に入れてしまって、教育は後日」という順番は成立しません。**入場前に教育する**のが前提です。

忙しくて後回しにすると、記録の日付で分かってしまいます。

### ② ひな形のまま、全項目にチェックが入っている

**40分で12項目すべてを本当にやったのか**、と見られます。実施したものだけにチェックを入れて、補足欄に具体を書くほうが信用されます。

### ③ 「安全帯」と書いてある

**2019年に名称が変わりました。** 現在は**要求性能墜落制止用器具**です。古いひな形を流用すると、ここが残ります。

### ④ 様式が元請の指定と違う

着手前に一言聞けば防げます。**作り直しは一番もったいない手戻り**です。

## よくある質問

### Q1. 全建統一様式はどこで手に入りますか？

複数のサイトが無料で配布しています。ただし**元請の指定様式があればそちらが優先**なので、まず元請に確認してください。

### Q2. 教育は何分くらいかければいいですか？

**内容次第です。** 時間を目標にしないでください。ただ、現場固有の話と避難経路の確認まで入れると、**30〜40分**にはなります。10分で終わる内容なら、何か抜けている可能性があります。

### Q3. 同じ会社の人が何度も入場します。毎回やるのですか？

**現場が変われば、やります。** 危険箇所も動線も緊急連絡先も違うからです。同じ現場への再入場の扱いは、元請のルールに従ってください。

### Q4. 教育をやるのは元請ですか、下請ですか？

**教育の実施義務は、その作業員を雇っている事業者（下請）にあります**（安衛法第59条）。元請は指導・援助の立場です（安衛則第642条の3）。実務では元請が場所と資料を用意して、合同で行うことが多いです。

### Q5. 記録は何年保存すればいいですか？

**特別教育は3年保存の定めがあります**（安衛則第38条）が、新規入場者教育の記録については法令に明文がない場合があります。**元請の指示と、労働基準監督署への確認で決めてください。**

## まとめ

| 項目 | ポイント |
|------|---------|
| **様式** | **まず元請に確認**。無ければ**全建統一様式第7号** |
| 根拠 | 安衛法第59条・安衛則第35条（教育義務は**下請**）／安衛則第642条の3（元請は**指導・援助**） |
| 教える内容 | **安衛則35条の8項目＋その現場固有のこと**。後者が本番 |
| 避難経路 | 口で言わず、**実際に歩かせる** |
| **最大の指摘** | **実施日が入場日より後**になっていないか |
| 書き方 | **場所と物を特定する**。「安全に配慮した」では意味がない |
| 用語 | **「安全帯」は旧称**。要求性能墜落制止用器具 |

新規入場者教育は、書類の作業に見えて**その人が無事に帰れるかどうかの話**です。ひな形を埋めることより、**危ない場所を本人に見せること**が本体だと思ってください。
