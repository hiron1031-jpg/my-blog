この記事では、**施工計画書の何が本当に大事なのか**を、実務の順番でまとめます。結論を先に言うと、**中身の完成度より「出す時期」のほうが重要**です。

## まず押さえる：施工計画書は「出さないと始められない」書類です

ここが工程表との一番の違いです。

| | 工程表 | **施工計画書** |
|---|---|---|
| 目的 | いつ・何をやるかの共有 | **どうやって安全に作るかの説明** |
| 提出先 | 社内・協力会社が中心 | **発注者（監督員）** |
| 出さないと | 段取りが悪くなる | **工事に着手できない** |

公共工事では、**着工前に施工計画書を提出し、監督員の確認を受けてから工事に入る**のが原則です。つまり**提出が遅れると、工程がそのまま後ろにずれます。**

<CalloutBox type="warn" title="新人が一番やりがちな失敗">
「完璧なものを作ってから出そう」として、**提出が遅れる**ことです。<br /><br />
施工計画書は、出したあとに監督員から指摘が入って直すのが普通です。**60点で早く出して、直すほうが正解**です。100点を目指して着工が遅れたら、それは現場の損失になります。<br /><br />
**まず提出期限を確認してください。** 中身を考えるのはそのあとです。
</CalloutBox>

## 施工計画書に書くこと

発注者や工事の種類によって様式は変わりますが、**土木の公共工事では概ね次の項目**が求められます。

| 項目 | 中身 |
|---|---|
| **工事概要** | 工事名・工期・工事場所・発注者・請負金額・工事内容 |
| **計画工程表** | 全体工程。ここで[工程表](/posts/koutei-hyou)が要る |
| **現場組織表** | 誰が何の担当か。主任技術者・監理技術者を明記 |
| **指定機械** | 契約で指定された機械があれば |
| **主要船舶・機械** | 使用する建設機械と規格 |
| **主要資材** | 使う材料と、規格・数量・メーカー |
| **施工方法（主要機械・仮設備計画・工事用地等）** | **ここが本体**。工種ごとの施工手順 |
| **施工管理計画** | 品質・出来形・写真をどう管理するか |
| **安全管理** | 危険箇所と対策、KY活動、安全教育の計画 |
| **緊急時の体制及び対応** | 事故・災害時の連絡網 |
| **交通管理** | 交通誘導員の配置・仮設道路・通行止めの計画 |
| **環境対策** | 騒音・振動・粉じん・濁水の対策 |
| **現場作業環境の整備** | 仮設事務所・トイレ・休憩所 |
| **再生資源の利用の促進と建設副産物の適正処理方法** | 発生土・産廃の行き先 |

<CalloutBox type="point" title="全部を同じ力で書かない">
上の全項目を同じ密度で書こうとすると終わりません。<br /><br />
**力を入れるのは「施工方法」と「安全管理」の2つ**です。ここが発注者の一番見るところで、差し戻しの理由もほぼここから出ます。<br /><br />
連絡網や仮設備の一般的な記述は、ひな形のままで問題ないことが多いです。
</CalloutBox>

## ゼロから書かない。ひな形と過去の実績を土台にする

**施工計画書は、流用が前提の書類です。**

理由は2つあります。

1. **項目の抜けを防げる**——決まった項目を網羅するのが目的なので、実績のある様式を使うほうが確実
2. **会社として説明が統一される**——毎回書き方が変わると、発注者も読みにくい

### 探す順番

| 順番 | 探すもの |
|---|---|
| 1 | **会社のひな形**（あれば最優先。書式が決まっていることが多い） |
| 2 | **同じ発注者・似た工種の過去の施工計画書** |
| 3 | 発注者が公開している**記載例・様式** |

**まず上司に「似た工事の施工計画書はありますか」と聞いてください。** ほぼ出てきます。

### ⚠️ ただし、流用元の「種類」を間違えると全滅します

ここが落とし穴です。**同じ「施工計画書」という名前でも、中身が別物のことがあります。**

| 流用元 | 使えるか |
|---|---|
| **同じ発注者・似た工種の工事** | ◎ 一番安全 |
| 同じ発注者・違う工種の工事 | ○ 構成は使える。施工方法は全部書き直し |
| **違う発注者の工事** | △ 様式そのものが違うことがある |
| **業務委託（工事ではない）の計画書** | **✗ 別物です** |

**特に最後です。** 調査・測量・設計などの**業務委託と、工事は求められる中身が違います。** 名前が似ているだけで、流用しても使えません。

## 【実体験】全ページに鉛筆で書き込まれて返ってきました

新人のころ、**初めて現場代理人を任された工事**でのことです。

施工計画書を作れと言われたものの、何も分かりませんでした。そこで上司に相談したら、**自分が持っていた「業務委託」の施工計画書**を見せてくれました。

それを真似して作り、監督員に提出しました。

数日後、呼び出されました。返ってきた施工計画書は、**全ページに鉛筆で注意書きが入っていました。**

<CalloutBox type="warn" title="何がまずかったのか">
**業務委託の計画書を、工事の計画書として出してしまった**ことです。<br /><br />
名前は同じ「施工計画書」でも、**業務委託と工事では求められる中身が違います。** 施工方法も、安全管理も、品質管理も、前提から違う。だから直しようがなく、全ページになったわけです。<br /><br />
上司に悪気はなく、私も「施工計画書」という名前だけで同じものだと思い込んでいました。**確認しなかったのは自分です。**
</CalloutBox>

いま思えば、聞くべきだったのは一言でした。

> **「この工事と同じ種類の、似た工種の施工計画書はありますか」**

「施工計画書はありますか」ではなく、**「同じ種類の」**を付ける。これだけで防げました。

### この失敗から学んだこと

| | |
|---|---|
| **流用元は自分で確認する** | 上司が渡してくれたものが、必ずしも適切とは限らない |
| **分からないなら、出す前に監督員に相談していい** | 「初めてなので、様式の参考をいただけますか」で済みます |
| **全ページ直されても、工事は進む** | 恥ずかしかったですが、直して再提出すれば通ります |

<CalloutBox type="point" title="鉛筆で書いてくれた監督員に、いまは感謝しています">
赤ペンではなく**鉛筆**でした。こちらが消して直せるようにしてくれていたわけです。<br /><br />
**差し戻しは、突き返されたのではなく「教えてもらった」ということ**です。当時は落ち込みましたが、あの1冊で施工計画書の考え方が身につきました。<br /><br />
**新人のうちに、たくさん直してもらってください。**
</CalloutBox>

### そして、直すのは「この現場に固有のところ」だけ

流用したまま出すと、必ずここで差し戻されます。

| 直すところ | 見落とすとどうなるか |
|---|---|
| **工事名・工期・請負金額** | 前の現場の名前が残っている＝即差し戻し |
| **現場組織表の氏名** | 担当者が違う人のまま |
| **現場の地形・周辺条件** | 川沿い／住宅地／交通量など、現場ごとに全く違う |
| **使う機械の規格** | 進入路の幅で入れる機械が変わる |
| **安全上の危険箇所** | **その現場で何が危ないか**。ここは流用できません |
| **近隣・環境への配慮** | 学校が近い、病院が近い、等 |

<CalloutBox type="warn" title="「前の現場の名前が残っている」が一番多い差し戻し">
笑い話のようですが、本当によくあります。**置換漏れです。**<br /><br />
提出前に、**前の工事名でファイル内を検索**してください。1回の検索で防げます。
</CalloutBox>

## 工事が変わったら、変更施工計画書を出す

**施工計画書は出して終わりではありません。**

工事内容・工法・工程・体制などが当初の計画から変わったら、**変更施工計画書**を提出します。

| よくある変更 | 例 |
|---|---|
| **設計変更** | 数量が増えた、構造が変わった |
| **工法の変更** | 現場条件が違って別の工法にした |
| **工程の大幅な変更** | 天候・設計変更で工期が動いた |
| **体制の変更** | 主任技術者・監理技術者が交代した |

<CalloutBox type="warn" title="出し忘れが一番まずい">
計画と違うやり方で工事を進めていて、**書類上は当初の計画のまま**——これが検査で見つかると厄介です。<br /><br />
「言われてから出す」ではなく、**変更が決まった時点で監督員に相談**してください。出すべきかどうかも含めて教えてもらえます。<br /><br />
**判断に迷ったら聞く。** 新人が自分で「これは出さなくていい」と決めないことです。
</CalloutBox>

## 施工計画書と、他の書類のつながり

施工計画書は単独の書類ではなく、**現場の書類の親玉**です。

| 施工計画書に書いたこと | それに対応する実務 |
|---|---|
| 計画工程表 | → [工程表](/posts/koutei-hyou)の更新（予定と実績） |
| 施工管理計画（写真管理） | → [施工写真](/posts/sekou-shashin)の撮影・整理 |
| 品質管理計画 | → 試験の実施と成績表 |
| 出来形管理計画 | → 出来形測定と管理図 |
| 安全管理 | → KY活動・安全教育の記録 |

**つまり、施工計画書に「やる」と書いたことは、全部やって記録に残す必要があります。**

<CalloutBox type="point" title="書きすぎないという判断も要ります">
「立派に見せよう」として、実施できない管理項目まで書き込むと、**自分の首を絞めます。** 書いたのにやっていない＝検査で指摘されます。<br /><br />
**実際にやることだけを書く。** これも大事な判断です。
</CalloutBox>

## 試験との関係

施工計画は、**第二次検定の記述テーマとしても出ます。**

| 試験 | つながる内容 |
|---|---|
| 土木 第二次 | 施工計画の**事前調査**（地形・地質・近隣・関係機関との協議）は定番の出題 |
| 造園 第二次 | 施工計画・工程管理は必須問題。R6から**全問必須** |
| 経験記述 | **施工計画書に書いた対策**が、そのまま経験記述のネタになります |

**実務で施工計画書を作った経験は、経験記述で一番使いやすい材料**です。課題・検討・対策・結果の流れが、そのまま計画書の構成と重なっているからです。

## よくある質問

### Q1. 施工計画書は何ページくらいになりますか？

**工事の規模によります。** 小規模なら20〜30ページ、大規模なら100ページを超えることもあります。ページ数を目標にしないでください。**必要な項目が漏れなく書けているか**が基準です。

### Q2. ひな形が会社にありません。どうすれば？

**発注者が記載例や様式を公開している**ことがあります（国土交通省の各地方整備局、自治体など）。まずは発注者の監督員に「参考にできる様式はありますか」と聞いてください。門前払いされることはまずありません。

### Q3. 監督員から差し戻されました。まずいですか？

**まったく普通です。** 筆者は初回、全ページに鉛筆を入れられました。むしろ一発で通るほうが珍しいくらいです。指摘された箇所を直して再提出すれば問題ありません。**大事なのは、指摘の理由を理解して次に活かすこと**です。同じ指摘を2回受けると、さすがに印象が悪くなります。

### Q4. 変更施工計画書は、どの程度の変更から必要ですか？

**判断に迷ったら監督員に聞いてください。** 発注者や工事の性格によって運用が違います。新人のうちは自分で線引きしないほうが安全です。「こう変わったのですが、変更計画書は必要でしょうか」と聞けば済みます。

### Q5. 施工計画書を作る時間がありません。

**現場が動き出す前が唯一のチャンス**です。着工後は日々の管理で時間が取れなくなります。**契約後、着工までの期間に集中して片付けてください。** ひな形を使えば、思っているより早く形になります。

## まとめ

| 項目 | ポイント |
|------|---------|
| **性格** | **着工前に出さないと工事に着手できない**書類 |
| **優先順位** | 完成度より**提出の早さ**。60点で早く出して直す |
| **作り方** | ゼロから書かない。**会社のひな形＋似た工事の実績**が土台 |
| **直すところ** | **この現場に固有のところだけ**。特に安全上の危険箇所 |
| 力を入れる項目 | **施工方法**と**安全管理**の2つ |
| 差し戻しの定番 | **前の工事名の置換漏れ**。提出前に検索を |
| **流用元** | **種類を間違えると全ページ直されます**（筆者の実体験） |
| **変更時** | 変更が決まった時点で監督員に相談。**出し忘れが一番まずい** |
| 注意 | **実施できないことは書かない**。書いたらやる必要があります |

施工計画書は、分厚くて最初は気が重い書類です。でも**一度作れば、次からは土台があります。** 最初の1冊を、期限内に出すことだけ考えてください。
