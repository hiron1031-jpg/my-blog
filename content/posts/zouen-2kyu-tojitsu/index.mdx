2級造園は11月の1日で第一次・第二次の両方を受ける可能性がある資格です（同時受験を選んだ場合）。朝〜夕方まで会場拘束＋初冬の寒さ＋会場が少ない地方在住者という独自の負荷があります。

この記事では、2級造園に独学・1発合格した筆者が **2級造園に特化した試験当日のチェックリスト** を解説します。

> 4資格共通の基本ルールは [施工管理技士 試験当日の持ち物・タイムスケジュール](/posts/shiken-tojitsu-jumbi) を参照。

## 2級造園 試験日と所要時間

| 検定 | 時期 | 所要時間 | 形式 |
|------|------|---------|------|
| 第一次検定 | 11月15日（日）午前 | **2時間10分** | マークシート4択 |
| 第二次検定 | 11月15日（日）午後 | **2時間** | 記述式 |

> ⚠️ 2級造園は第一次・第二次が同日。同時受験を選んだ場合、朝〜夕方まで会場拘束になります。試験日は年度で変動するので [全国建設研修センター](https://www.jctc.jp/) で必ず確認。

## 2級造園 必須持ち物（共通）

| 項目 | 注意点 |
|------|------|
| **受験票** | 顔写真貼付済み |
| 写真付き本人確認書類 | 学生証だけでは不可。運転免許 or マイナンバー |
| HBの鉛筆 5本以上 | 第一次マークシート用 |
| 消しゴム 2個 | 1個は予備 |
| 腕時計（アナログ） | スマートウォッチ不可 |

> 💡 17歳・大学生・植木屋見習いの受験者は学生証・社員証のみで来てしまう失敗が多い。**写真付き公的身分証**を必ず持参。

## 【11月】初冬・1日通し受験の対策

11月の2級造園は初冬の寒さ＋1日で2試験の体力勝負。寒さで集中力が削がれないように、また昼食で午後の眠気を作らないように注意。

### 同日受験の追加持ち物・タイムスケジュール

| 項目 | 理由 |
|------|------|
| **黒の油性ボールペン 3本以上** | 第二次の記述用（フリクション不可） |
| 下書き用シャーペン | 問題用紙余白で下書き |
| 昼食（おにぎり等） | 会場周辺コンビニは混雑 |
| チョコ / ラムネ | 午後の集中力ブースト |
| カイロ（貼る・貼らない両方） | 11月の会場は底冷え |
| ひざ掛け / ストール | 持ち込み可な会場が多い |
| マスク | 乾燥・風邪予防 |
| 使い慣れた要点ノート（用語・数値） | 昼休みの直前確認用 |

> ⚠️ 昼食は重い丼物・ラーメンは避ける。**おにぎり2個＋温かい味噌汁**くらいが筆者推奨。午後の眠気で第二次が壊滅します。

当日のタイムスケジュール（モデル）：

| 時刻 | やること |
|------|---------|
| 6:30 | 起床・朝食 |
| 7:30 | 自宅出発（路面凍結 or 落ち葉スリップ注意） |
| 9:00 | 会場着・トイレ・カイロ貼る |
| 9:00〜9:30 | 要点ノート確認 |
| 9:45頃 | **第一次検定 開始** |
| 11:45頃 | 第一次終了 |
| 12:00〜13:00 | **昼食・トイレ・用語ノート確認** |
| 13:30頃 | **第二次検定 開始** |
| 15:30頃 | 第二次終了 |

> ⚠️ 試験開始時刻は受験票記載の時刻が正です。年度・会場で異なります。

昼休み60分の使い方：第一次の出来が悪くても絶対に引きずらないことが最重要です。

1. トイレ（午後の途中退室は集中力が切れる）
2. 昼食を10〜15分で軽く
3. 二次の用語・数値ノートをペラペラ流し読み（30分）
4. **5分仮眠**（机に伏せる程度）

## 2級造園 試験中の戦略・前日の過ごし方

### 第一次・第二次の戦略

**合格ラインは60%**。全問正解は不要で、植物名問題（樹種・草本）は捨て問題化してもOK。1問2分以上悩んだら印をつけて次へ。マークシートは10問ごとに番号ズレを確認してください。

<ZouenKeikenNotice variant="inline" target="2kyu" />

第二次検定はR7の場合、問題1（施工管理）・問題2（安全管理）の**2問とも必須**でした。

- **確実に書ける設問から埋める**（全問必須なので選ぶ余地はない）
- 「植栽工」「造園土工」「修景施設工」の用語を正確に使う
- 空欄は作らない（部分点狙い）
- 植栽・支柱・養生・剪定あたりが頻出

> 💡 暗記すべきは「自分の工事経験」ではなく「造園の用語と数値」。工事数量表の読み取りに慣れておくと本番で慌てません。

## 2級造園 会場・前泊と若手受験者のポイント

2級造園も土木より受験者数が少なく、会場も限られます。主要会場は札幌・仙台・東京・名古屋・大阪・広島・高松・福岡・那覇など主要都市のみ。

地方在住者の前泊段取り：

| 項目 | 推奨 |
|------|------|
| ホテル予約 | 試験日が決まったら**即予約** |
| ホテル選び | 会場から徒歩圏が最優先 |
| 朝食 | 朝食付きプランが時短に有利 |
| 11月の特注意 | 北日本は初雪・路面凍結リスクあり |

> 💡 11月は3連休（文化の日付近）に当たる年があり、**ホテル料金が高騰**します。早期予約が鉄則。

## 17歳・植木屋見習い受験者へのアドバイス

2級造園は17歳以上で実務経験ゼロでも第一次検定が受けられるため、若手・植木屋の見習いの受験が増えています。

若手受験者が注意すること：

1. 本人確認は学生証・社員証だけでは不可。**写真付き公的身分証**を持参
2. 作業着で来場OK（造園会社員は作業着のまま来る人も）
3. 休憩時間にスマホ禁止（カバンに入れて電源OFF）
4. 保護者・先輩同伴NGエリアあり
5. 周囲は30〜60代の造園職人が多い → 物怖じしない

### 前日の過ごし方

✅ やるべきこと：持ち物の最終確認（2回）・経路再確認（11月：初雪・凍結）・要点ノート流し読み（30分）・**22時就寝**・前泊なら暖房早めにON

❌ やってはいけないこと：新しい問題集に手を出す・徹夜詰め込み・暴飲暴食・前泊先での飲み歩き・会社の忘年会（当日に頭が回らない）

## よくある質問（FAQ）

### Q1. 第一次と第二次を同日に受けるのはきつくないですか？

体力的にはきついですが、年1回しかない試験を1日で完結できるというメリットが大きいです。「第一次だけ合格して第二次は来年」にすると、また1年待つことになります。コツは昼休みを有効活用（トイレ→軽食→用語・数値ノート確認→仮眠5分）と、午前の第一次の出来を引きずらないメンタル切り替えです。

### Q2. 11月の試験、服装の注意点はありますか？

11月は重ね着で温度調節できる服装が最適です。「暑ければ脱げる、寒ければ着込める」状態が理想で、薄手のインナー＋長袖シャツ＋薄手のフリースorカーディガンの**3層構造**がおすすめです。

### Q3. 昼休みに第一次の答え合わせや採点をしてもいいですか？

やめることを強くおすすめします。自己採点で悪い結果が出ると午後の第二次に精神的ダメージが及びます。問題用紙は持ち帰れますが、確認は帰宅後で十分。昼休みは**第二次で使う用語・数値の確認**に集中してください。
