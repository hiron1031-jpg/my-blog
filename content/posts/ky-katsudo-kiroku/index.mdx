「毎朝KYをやっているが、**書くことが毎日同じ**になっている」
「**様式が会社になくて**、何を書けばいいのか分からない」
「**リスクアセスメントと何が違う**のか説明できない」

KY活動は、現場でいちばん回数の多い安全活動です。それなのに、**記録の書き方を教わる機会がありません。**

この記事では、記録に何を書くかを実務の順番でまとめます。架空の記入例も置いてあるので、そのまま形を真似して使ってください。

<CalloutBox type="target">
- KYボード・KY用紙を初めて書く新人監督、職長
- 毎日同じ内容になってしまっている人
- 元請から「具体的に書いて」と返された人
</CalloutBox>

<CalloutBox type="conclusion" title="この記事の結論">
- **KY活動の様式は法令で決まっていません。** だから元請の指定が最優先です
- 中身は**4ラウンド法**（どんな危険が→これがポイント→どうする→こうする）
- **「注意する」「気をつける」で終わると、記録の意味がなくなります**
- 書くのは「**誰が・何に・どうやって**」。主語と物と動作を入れてください
- リスクアセスメントとは別物。**KYは毎日・現場で・即決**、RAは手順を変えるとき
</CalloutBox>

## まず：様式は法令で決まっていません

ここを誤解している人が多いので、最初に書きます。

**労働安全衛生法に「KY活動をやりなさい」「この様式で記録しなさい」という条文はありません。**

法律が定めているのは、こちらです。

> **労働安全衛生法 第28条の2（事業者の行うべき調査等）**
> 事業者は、（中略）危険性又は有害性等を調査し、その結果に基づいて、（中略）必要な措置を講ずるように**努めなければならない**。

これが**リスクアセスメント**で、**努力義務**です。KY活動はこれとは別の、現場の自主的な活動として広まったものです。

<CalloutBox type="point" title="では、なぜ毎日やるのか">
**元請が求めるからです。** 建設現場では、入場時の約束事として「毎朝KYを実施し、記録を提出すること」が条件になっているのが通例です。

法令の義務ではなくても、**現場に入る条件としては実質的に必須**、というのが実態です。

だから様式も、**元請が指定するものがあればそれが最優先**になります。
</CalloutBox>

| 順番 | 確認すること |
|---|---|
| **1** | **元請の指定様式・指定ボードがあるか**（これが最優先） |
| 2 | 会社に既存のひな形があるか |
| 3 | 無ければ、この記事の項目で作る |

## リスクアセスメントとの違い

「同じでは？」と聞かれたときに答えられるように、整理しておきます。

厚生労働省の資料に、両者を並べた表が載っています。要点はこの3つです。

| | リスクアセスメント | **KY活動** |
|---|---|---|
| いつ | 設備や作業手順を**変えるとき** | **毎日・作業の都度** |
| どこで | 主に事務所・会議室 | **主に作業現場** |
| どのように | 時間とお金をかけて改善 | **即決・即断で回避** |

- **リスクアセスメント**＝職場に潜む危険を**根本的に減らす**ため。危険の程度を数値化して優先順位をつけます
- **KY活動**＝その日の作業に潜む危険に**すぐ対応する**ため。危険の有無で判断し、その場で決めます

**どちらかがあれば片方は要らない、というものではありません。** 役割が違います。

## 中身の進め方：4ラウンド法

KY活動の標準的な進め方です。厚生労働省の資料でも、この手順が紹介されています。

| ラウンド | 問いかけ | やること |
|---|---|---|
| **1R** | どんな危険が潜んでいるか | 今日の作業の危険を**出せるだけ出す** |
| **2R** | これが危険のポイントだ | 出た中から**今日いちばん危ないもの**を絞る |
| **3R** | あなたならどうする | 対策の案を**作業員から出してもらう** |
| **4R** | 私たちはこうする | **今日やる行動目標**を1つ決める |

最後は**指差し呼称**で確認します。

<CalloutBox type="point" title="3Rを飛ばさないでください">
時間がないとき、監督が1Rから4Rまで一人で言ってしまいがちです。

でも**作業員に考えてもらう3Rを飛ばすと、KYは「聞き流す朝礼」になります。** 一人に一つ言ってもらうだけで、その日の事故の見え方が変わります。
</CalloutBox>

## 架空の記入例

**以下はすべて架空です。** 実在の会社・現場・人物とは関係ありません。

### ■ 基本情報

| 項目 | 記入例 |
|---|---|
| 実施年月日 | 令和8年11月5日 |
| 工事名 | ◯◯地区 道路改良工事 |
| 作業場所 | 起点側 法面部 |
| 天候・気温 | 晴れ／9℃ |
| 実施時刻 | 8:00〜8:10 |
| 会社名（職長名） | 有限会社テスト工業（見本 太郎） |
| 参加人数 | 5名 |

### ■ 今日の作業

| 項目 | 記入例 |
|---|---|
| 作業内容 | 法面部の掘削、残土積込み |
| 使用する機械 | バックホウ0.45m³、ダンプ10t |
| 使用する資材 | 敷鉄板、単管バリケード |

### ■ KYの中身

**1R どんな危険が潜んでいるか**

- バックホウの旋回範囲に人が入り、はさまれる
- 掘削した法面の肩が崩れ、下にいる作業員が埋まる
- ダンプの後退時に、誘導員が死角に入り接触する
- 朝の霜で敷鉄板が滑り、転倒する

**2R これが危険のポイントだ**

> **バックホウの旋回範囲に人が入り、はさまれること**

**3R あなたならどうする（作業員から出た案）**

- 旋回範囲をカラーコーンとバーで囲う
- オペレーターと合図を事前に決める
- 機械から離れた位置で待機する場所を決めておく

**4R 私たちはこうする（今日の行動目標）**

> **「バックホウの旋回範囲は、バリケードで囲い、中に入るときは必ずオペレーターと目を合わせて合図してから入る」**

**指差し呼称**

> 「旋回範囲、進入禁止、ヨシ！」

<CalloutBox type="point" title="この記入例で見てほしいところ">
- 1Rの危険が**「どこで・何が・どうなる」**まで書いてあります
- 4Rの目標に**「バリケード」「目を合わせて合図」**という具体的な動作が入っています
- **「注意する」「気をつける」が1回も出てきません**
</CalloutBox>

## 「注意する」で終わらせない

ここがこの記事の本題です。

| ❌ これでは記録の意味がない | ✅ こう書く |
|---|---|
| 転倒に注意する | 朝の霜で敷鉄板が滑るので、**歩く位置を鉄板の外側に変える** |
| 重機に注意する | **旋回範囲をバリケードで囲い**、入るときは合図してから |
| 足元に気をつける | **配線を通路の外にまとめ**、残材はその都度片付ける |
| 安全第一で作業する | （目標になっていません。書き直してください） |

### なぜダメなのか

**「注意する」は、行動ではないからです。**

明日の朝、同じことを書けてしまいます。そして**何も変わりません。**

書くときに自分へ問いかけてほしいのは、この3つです。

1. **誰が**やるのか
2. **何に**対してやるのか（物・場所を特定する）
3. **どうやって**やるのか（動作で書く）

この3つが入っていれば、その記録は使えます。

## よくある失敗

### ① 前日のコピーになっている

**作業が変われば危険も変わります。** 同じ内容が3日続いたら、その記録は見られていません。

作業内容が本当に同じ日でも、**天候・人員・使う機械**のどれかは変わっているはずです。

### ② 2Rで全部に丸をつけている

「全部危ない」は、**優先順位をつけていないのと同じ**です。1つに絞るから、その日の全員の頭に残ります。

### ③ 4Rが「安全第一で作業する」になっている

行動目標ではなくスローガンです。**その場で何をするか**を書いてください。

### ④ 書いてから朝礼をしている

記録を先に作って、朝礼は読み上げるだけ——これでは3Rがありません。**その場で出た言葉を書く**のが本来の順番です。

### ⑤ 新規入場者がいる日に、いつも通りやっている

その日初めて入る人は、**現場の危険を知りません。** 新規入場者教育とセットで考えてください。

## よくある質問

### Q1. KY活動は法律で義務づけられていますか？

**KY活動そのものを名指しで義務づける条文は、労働安全衛生法にはありません。** 法律が定めているのは第28条の2のリスクアセスメント（努力義務）です。

ただし建設現場では、**元請が入場の条件として実施と記録の提出を求めるのが通例**です。実務上はやることになります。

### Q2. 記録はどのくらい保存しますか？

**法令に定めがある書類ではないため、保存期間も決まっていません。** 元請や自社の規定に従ってください。労働災害が起きたときに経緯を示す資料になるので、**工事完了まで残しておく**のが実務では一般的です。

### Q3. 毎日やらないといけませんか？

厚生労働省の資料では、KY活動は「**毎日又は作業の都度**」と整理されています。作業内容が変わるとき、新しい人が入るとき、天候が大きく変わったときは、改めて実施してください。

### Q4. ボードに書くのと、用紙に書くのは違いますか？

**どちらでも構いません。** 元請がボードの掲示を求める現場もあれば、用紙の提出を求める現場もあります。ボードの場合は、**その日の写真を撮って記録として残す**のが確実です。

### Q5. 一人作業の日はどうしますか？

一人でも、**作業前に危険を確認して記録を残す**こと自体は同じです。ただし3R（意見を出し合う）ができないため、**一人作業そのものの可否**を元請に確認してください。

### Q6. リスクアセスメントもやらないといけませんか？

**第28条の2は努力義務**とされています。KY活動とは目的が違うので、置き換えにはなりません。実施の要否や範囲は、**所轄の労働基準監督署や元請に確認**してください。

## まとめ

KY活動の記録で大事なのは、この3つだけです。

| | |
|---|---|
| **様式** | 法令で決まっていない。**元請の指定が最優先** |
| **中身** | 4ラウンド法。**3Rを飛ばさない** |
| **書き方** | 誰が・何に・どうやって。**「注意する」で終わらせない** |

毎朝の10分は、現場でいちばん回数の多い安全活動です。**形だけになるか、本当に効くかは、記録の書き方で決まります。**
