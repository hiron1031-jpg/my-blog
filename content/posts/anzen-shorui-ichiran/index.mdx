現場に入る前に、**書類をそろえろ**と言われます。

でも、**何を・誰が・いつ・誰に出すのか**は、どこにも一覧で書いてありません。元請から渡されるのは空欄の様式だけ。

この記事は、**その一覧**です。

<CalloutBox type="target">
- 元請から「安全書類を出して」と言われて固まっている人
- 初めて下請として現場に入る会社の担当者
- 新人に書類を教える立場になった人
</CalloutBox>

<CalloutBox type="conclusion" title="先に結論">
- 安全書類は**書類ごとに「作る人」が違います**。ここを間違えると全部やり直しになります
- **様式は、まず元請に確認**。指定がなければ**全建統一様式**が業界標準
- ⚠️ **様式番号はあてになりません。** 番号ではなく**書類名**で話してください
- 提出のタイミングは**「契約したら」「入場前」「持ち込む前」**の3つに分かれます
</CalloutBox>

## 早見表【誰が・いつ・誰に】

まず全体です。詳しくは、このあと1つずつ書きます。

| 書類 | 作る人 | 出す先 | いつまでに |
|---|---|---|---|
| **再下請負通知書** | 二次以降の下請 | 元請 | 契約したら |
| **作業員名簿** | 下請（各社） | 元請 | **入場前** |
| **新規入場者教育の記録** | 下請（教育は元請が実施） | 元請 | **入場当日** |
| **持込機械等使用届** | 持ち込む会社 | 元請 | **持ち込む前** |
| **有資格者一覧** | 下請（各社） | 元請 | 入場前 |
| **工事安全衛生計画書** | 下請（各社） | 元請 | 着手前 |
| **施工体制台帳・施工体系図** | **元請** | 発注者（公共工事） | 下請契約後 |

> 📌 **下請が作るものと、元請が作るものが混ざっています。** ここが混乱のもとです。

---

## 📌 いちばん大事なこと：番号で呼ばない

よそのサイトには「作業員名簿は**全建統一様式第5号**」と書いてあります。

**その番号は、発注者や自治体によって違います。**

施工体制台帳・再下請負通知書・施工体系図・作業員名簿を**まとめて1つの番号**にしている自治体もあります。

<CalloutBox type="warn" title="番号で聞くと、話が通じません">
❌ 「第5号を出せばいいんですよね？」
✅ 「**作業員名簿**を出せばいいんですよね？　様式は御社の指定がありますか？」

**元請に確認するときは、必ず書類名で。** 様式はたいてい元請が持っています。
</CalloutBox>

## 1. 再下請負通知書

| | |
|---|---|
| 作る人 | **二次以降の下請** |
| 出す先 | **元請**（一次下請ではありません） |
| いつ | 契約したら |

### ここを間違える人が多い

**一次下請は、再下請負通知書を出しません。**（再下請していなければ）

二次・三次の下請が、**一次を飛ばして元請に直接出します。**

| 立場 | 再下請負通知書 |
|---|---|
| 元請 | 作らない（受け取る側） |
| 一次下請 | **再下請していなければ不要** |
| 二次下請 | **必要**（元請へ） |
| 三次下請 | **必要**（元請へ） |

> 元請はこれを集めて**施工体制台帳**を作ります。だから元請は催促してきます。

## 2. 作業員名簿

| | |
|---|---|
| 作る人 | **下請（各社が自社の分）** |
| 出す先 | 元請 |
| いつ | **入場前** |

**社会保険の欄があります。** 建設業法の改正で施工体制台帳に社会保険の加入状況を書くことになり、国土交通省のガイドラインは **「実質的に作業員名簿の作成が義務化された」** と書いています。

**空欄だと、元請から指導が入ります。** 現場に入れないこともあります。

## 4. 持込機械等使用届

| | |
|---|---|
| 作る人 | **その機械を持ち込む会社** |
| 出す先 | 元請 |
| いつ | **持ち込む前** |

バックホウ、トラック、発電機、電動工具まで。**何を持ち込むかを先に届け出ます。**

### 添えるもの

| | |
|---|---|
| 機械の**仕様・年式** | |
| **特定自主検査の記録**（車両系建設機械など） | 検査標章の写真を求められることも |
| **運転する人の資格** | 技能講習修了証の写し |

> ⚠️ **当日持ってきて、その場で届けを出すのでは遅いです。** 検査記録や資格の写しをそろえる時間が要ります。

**誰が、何の資格を持っているか**の一覧です。

- 車両系建設機械、玉掛け、小型移動式クレーン（技能講習）

## 7. 施工体制台帳・施工体系図（元請が作る）

| | |
|---|---|
| 作る人 | **元請（発注者から直接請け負った特定建設業者）** |
| 出す先 | **公共工事は発注者へ写しを提出** |
| 根拠 | 建設業法第24条の8／公共工事入札契約適正化法第15条 |

### 作成義務が生じるのは

| | |
|---|---|
| **公共工事** | **下請契約の金額にかかわらず必要** |
| **民間工事** | 下請契約の総額が**5,000万円**（建築一式は**8,000万円**）以上 |

<CalloutBox type="warn" title="⚠️ 金額は改正されています">
この金額は何度か引き上げられています。**古い資料には4,000万円（建築一式6,000万円）と書かれているものがあり、国の機関のPDFでも更新されていないものを見かけます。**

**必ず、最新の建設業法施行令と、発注者の指示で確認してください。**
</CalloutBox>

> 📌 **施工体系図は、工事完了後10年間の保管**が義務づけられています（営業に関する図書）。

## よくある質問

### Q1. 全部そろえてから出すべきですか？

**いいえ。そろった順に出してください。**

まとめて出そうとすると、1つ足りないだけで全部が止まります。**元請も、来た順にチェックしたいはずです。**

### Q2. 様式が元請から来ません。どうすれば？

**催促してください。** 遠慮する場面ではありません。

元請が様式を持っていないことは、まずありません。**「御社の指定様式はありますか。無ければ全建統一様式で作ります」**と聞くのが早いです。

### Q3. 提出が遅れてしまいました。

**すぐ元請に連絡してください。** 黙っていると、**当日に現場へ入れません。**

人が入れないと工程が止まります。**早く言えば、仮で入れてもらえる場合もあります。** 遅れた理由より、いつ出せるかを伝えてください。

### Q4. 一人親方ですが、作業員名簿は要りますか？

**要ります。** 社会保険の欄の書き方が雇用されている人と違うので、そこは別途まとめています。

👉 [作業員名簿の書き方【社会保険欄と一人親方】](/posts/sagyoin-meibo)

### Q5. KY活動の記録も安全書類ですか？

**提出書類というより、現場で毎日つける記録**です。元請に毎日出す現場もあれば、自社で保管する現場もあります。

👉 [KY活動記録の書き方【記入例つき】](/posts/ky-katsudo-kiroku)

## まとめ

| | |
|---|---|
| 何が一番大事か | **書類ごとに「作る人」が違う**こと |
| 様式 | **まず元請に確認。** 無ければ全建統一様式 |
| 番号 | **あてにしない。** 書類名で話す |
| 出し方 | **そろった順に出す。** まとめようとしない |
| 遅れたら | **すぐ言う。** 黙っていると現場に入れない |

書類は、**覚えるものではなく、調べて出すもの**です。この表を手元に置いておけば足ります。
