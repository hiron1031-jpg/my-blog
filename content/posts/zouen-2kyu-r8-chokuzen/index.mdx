令和8年度の2級造園施工管理技術検定は **11月15日（日）**。第一次検定が午前、第二次検定が午後で、**同じ日に両方を受ける**のが2級造園の特徴です。

この記事を書いている時点で、残り約7週間。「一次の勉強で手一杯で、二次まで手が回らない」という状態の方に向けて、**2級造園に独学・一発合格した筆者が、残り7週間の進め方**をまとめます。

すでに前期（6月7日）で第一次に合格している方は、**11月15日は第二次検定だけ**。この記事の「第二次対策」の章に集中してください。

## 最大の落とし穴：二次を後回しにすると詰みます

同時受験で一番多い失敗が、これです。

> 「まず一次に受からないと意味がないから、一次だけやろう」
> → 一次の手応えはあったが、午後の二次で手が止まる

**一次と二次は同じ日です。** 一次の結果を見てから二次を準備する時間は**存在しません**。

| | 一次（マークシート） | 二次（記述） |
|---|---|---|
| 必要なこと | **暗記** | **書いて慣れる** |
| 効く時期 | **直前ほど効く** | 早く始めるほど効く |
| 詰め込み | できる | **できない** |

だから順番は、**時間のかかる二次から先に着手する**です。

## ⚠️ 造園の二次は、経験記述が出題されません

ここを間違えると、**準備そのものが無駄になります。**

<CalloutBox type="warn" title="令和6年度から出題形式が変わりました">
令和5年度（R5）までは、**問題1が経験記述**（自分が担当した造園工事について書く）でした。<br /><br />
**令和6年度（R6）から、経験記述は出題されていません**（R6・R7の公式試験問題で確認済み）。現在は**工事数量表と工事条件を読み取って答える技術記述**が中心です。<br /><br />
つまり、**工事名・工期・自分の立場を暗記する準備は一切不要**です。ネット上にはR5以前の情報がそのまま残っているので注意してください。
</CalloutBox>

浮いた時間は、そのまま技術記述の対策に回してください。**ここが今年の受験者の差がつくポイント**です。

### R7の出題構成

| 問題 | 出題内容 |
|------|------|
| **問題1（必須）** | 施工管理（高木植栽・支柱・施肥・高木移植・地被類植栽・工程管理） |
| **問題2（必須）** | 安全管理（ツールボックスミーティング・バックホウ・移動式クレーン・草刈り機） |

**選択問題はありません。** 全問必須なので、苦手分野を捨てられないのが現行形式の厳しさです。

## 残り7週間の日別プラン

| 期間 | 第二次検定 | 第一次検定 |
|------|------|------|
| **第7〜6週**（〜10/10頃） | **R7・R6の過去問を実際に解く**。答えを見ながらでいい。形式に慣れる | 植栽工・維持管理の過去問を回す |
| **第5〜4週**（〜10/24頃） | 頻出テーマ（植栽・支柱・剪定・安全）の**用語と数値を書けるようにする** | 施工管理法・法規を追加 |
| **第3〜2週**（〜11/7頃） | もう一度R7を**時間を計って通す**。書ける量を体で覚える | **暗記の追い込み**。×問題だけ回す |
| **直前1週間** | 用語の確認と音読のみ。新しい問題はやらない | 重要数値の即答テストを毎日 |
| **前日** | 持ち物確認・会場確認。22時就寝 | 新しい問題はやらない |

<CalloutBox type="point" title="なぜ一次の暗記を後ろに置くのか">
マークシートの暗記は**忘れる前に本番が来るほうが有利**です。9月に完璧に覚えても、11月には抜けています。<br /><br />
逆に記述は「書ける状態」になるまで時間がかかり、**直前に詰め込めません**。だから先に手を付けます。
</CalloutBox>

## 第一次検定：頻出分野の優先順位

全40問のうち**24問（60%）**で合格です。**16問は落としていい**と考えると、狙う場所が決まります。

| 分野 | 出題数の目安 | 優先度 |
|------|-------------|--------|
| **施工管理法（工程・品質・安全）** | 10〜12問 | ★★★★★ |
| **植栽工（樹木・草花）** | 8〜10問 | ★★★★★ |
| **維持管理（剪定・施肥・病害虫）** | 5〜7問 | ★★★★★ |
| 修景施設工（園路・竹垣・石組） | 5〜6問 | ★★★★☆ |
| 法規（労安法・建設業法） | 5〜7問 | ★★★★☆ |
| 造園土工・基盤整備 | 4〜5問 | ★★★★☆ |

**上位3分野だけで23〜29問**あります。ここを固めれば合格ラインにほぼ届きます。

<CalloutBox type="point" title="2級造園は「維持管理」の比率が高い">
1級は工事計画が中心ですが、**2級は剪定・施肥といった日常の造園作業が多く出ます。** 現場で毎日やっていることがそのまま点になる分野なので、**造園会社で働いている方はここが一番の得点源**です。
</CalloutBox>

詳しい分野別の攻略は → [2級造園 第一次検定の頻出分野と対策](/posts/zouen-2kyu-hinshutu)

## 一次・二次の両方で効く重要ワード

**同日受験の最大の利点は、覚えたことが午前と午後の両方で使えること**です。優先して固めてください。

### 植栽工

| 項目 | 内容 |
|------|------|
| 移植適期 | 落葉樹は**落葉期**（休眠期）、常緑樹は**春の萌芽前**または梅雨期 |
| 植え付けの水決め | **水極め**（水を注ぎながら埋め戻す）。粘土質では**土極め** |
| 支柱の種類 | **八ツ掛け・布掛け・添え柱・鳥居型** |
| 支柱の結束 | 樹皮を傷めないよう**杉皮・シュロ縄**で幹当てをする |
| 根鉢 | 掘り取った根の土のかたまり。**根巻き**で崩れを防ぐ |
| 活着 | 移植後に根が伸び、樹木が定着すること |

### 維持管理

| 項目 | 内容 |
|------|------|
| 剪定の目的 | 樹形の維持、**通風・採光**の確保、病害虫の予防 |
| 忌み枝 | **徒長枝・からみ枝・ふところ枝・逆さ枝・胴吹き枝** |
| 施肥の時期 | **寒肥**（休眠期）と**追肥**（生育期・お礼肥） |
| マルチング | 地表を覆って**乾燥防止・雑草抑制・地温調整** |

### 安全管理（二次で必出）

| 項目 | 内容 |
|------|------|
| TBM | **ツールボックスミーティング**。作業前に危険を全員で確認 |
| 高所作業 | 高さ**2m以上**は作業床の設置、または墜落制止用器具を使用 |
| 墜落制止用器具 | 現在は**「要求性能墜落制止用器具」**（旧称の「安全帯」は使わない） |
| 移動式クレーン | 定格荷重を超える使用の禁止、**旋回範囲への立入禁止** |
| 刈払機 | 飛石防止の**保護具**、周囲の**立入禁止措置** |

<CalloutBox type="point" title="1周3分の即答テスト">
表の左側だけ見て、右側を言えるか試してください。**朝・昼・寝る前の1日3回**、これを続けるだけで定着します。<br /><br />
午前の一次でも午後の二次でも、そのまま使えます。
</CalloutBox>

## 第二次検定：書き方の3つのコツ

### ① 用語は正確に、略さない

造園の記述は**用語の正確さがそのまま点**になります。

- ❌「支柱をつけた」 → ✅「**八ツ掛け支柱**を設置した」
- ❌「肥料をやった」 → ✅「**寒肥**として緩効性肥料を施用した」
- ❌「安全帯」 → ✅「**要求性能墜落制止用器具**」

### ② 数値が問われたら必ず単位まで

工事数量表から読み取る問題では、**単位を落とすと減点**されます。樹高（H）・幹周（C）・枝張（W）の記号もそのまま使ってください。

### ③ 空欄を作らない

**部分点があります。** 分からない設問でも、関連する用語を書けば点が入る可能性が残ります。空欄は確実に0点です。**最後の10分は「埋まっていない欄を探す時間」**と決めておいてください。

書き方の詳しいテンプレは → [2級造園 第二次検定 記述問題対策](/posts/zouen-2kyu-2ji-kijutsu)

## 試験当日：1日をどう乗り切るか

**朝から夕方まで会場にいます。** 体力配分が合否に影響します。

| 時間 | やること |
|------|------|
| 朝 | 会場到着は**45分前**。直前に見るのは重要数値のシート1枚だけ |
| 午前（一次） | 2時間10分。**分からない問題は飛ばして最後に戻る**。マークのずれに注意 |
| **昼休み** | **一次の答え合わせをしない**。友達との照合もしない |
| 午後（二次） | 2時間。まず全問に目を通し、書ける設問から埋める |
| 最後の10分 | **空欄探し** |

<CalloutBox type="warn" title="昼休みに自己採点してはいけません">
「午前で落ちたかも」と思った瞬間、午後の記述は書けなくなります。**そして、その感触はよく外れます。**<br /><br />
昼休みは**午後の二次の用語を見返す時間**にしてください。食事は軽めに。満腹だと午後に眠くなります。
</CalloutBox>

## よくある質問

### Q1. 二次がまったく手つかずです。7週間で間に合いますか？

**間に合います。** 経験記述がなくなったぶん、2級造園の二次は**過去問のパターンを覚えれば戦える試験**になりました。R7・R6の2年分を解いて形式に慣れ、頻出の用語を書けるようにすれば、60%は十分狙えます。

### Q2. 一次だけ受かって、二次は来年でもいいですか？

**制度上は可能です。** ただし2級造園の第二次検定は**後期（11月）にしかありません**。今年見送ると、次のチャンスは1年後です。同日受験を申し込んでいるなら、**午後も必ず受けてください**。書けなくても部分点があります。

### Q3. 前期（6月）に第一次に合格しています。何をすればいいですか？

**11月15日は第二次検定だけ**です。この記事の「第二次検定」の章と、[記述問題対策](/posts/zouen-2kyu-2ji-kijutsu)に集中してください。一次の暗記は不要なので、**7週間まるごと記述に使えます**。かなり有利な状態です。

### Q4. 経験記述の例文を暗記していました。無駄になりますか？

**試験対策としては使いません。** ただし、**受験申込みの実務経験証明とは別の話**なので、そちらは引き続き必要です。暗記に使っていた時間は、今日から技術記述に振り替えてください。

### Q5. 参考書を買い足すべきですか？

**残り7週間で新しい参考書を開くのは危険です。** 手持ちの教材と[無料の過去問PDF](/pastproblems)で十分です。二次用の教材を買う場合だけ、**R6以降の現行形式に対応しているか**を必ず確認してください（古い版は経験記述中心のままです）。
