## ①記録を守る — ここが最優先

### 1. 防水マジック（油性マーカー）— 濡れた面に書ける

**これを知っているかどうかで、雨の日の仕事の速さが変わります。**

普通の油性マジックは、**濡れた面ではインクが弾かれて書けません**。木杭・型枠・鉄板・コンクリート面に印を付けたいのに、水滴があるだけで線が乗らない。拭いても、雨ならすぐまた濡れます。

**濡れた面でも書けるタイプの油性マーカー**があります。1本持っておくだけで、雨の日の墨出し・マーキングが止まりません。

### 2. 耐水野帳 — ふやけない・にじまない

測量野帳は現場監督の必需品ですが、**普通の紙は雨に一度当たっただけでふやけます**。ページがくっつき、鉛筆の字はにじみます。

**耐水紙の野帳**なら、濡れたまま書けて、乾かせば元に戻ります。雨の多い時期は、これに替えるだけでストレスが激減します。

### 8. レインウェア上下 — 「透湿」を必ず確認

**安いカッパは蒸れて、中が汗でびしょ濡れになります。** 結局濡れるなら意味がありません。**透湿性（湿気を外に逃がす性能）**があるものを選んでください。

作業用は**上下セパレート**が基本です。ポンチョは風でめくれ、機械にも巻き込まれる恐れがあります。

## 装備の前に：雨の日の安全管理

グッズを揃えても、**雨の日そのもののリスク**は消えません。

| リスク | 対応 |
|---|---|
| **滑る** | 足場・鉄板・法面は濡れると滑る。作業開始前に点検し、滑り止めを敷く |
| **見えない** | 視界が悪化する。重機の誘導は合図者を明確にし、反射ベストを着用 |
| **崩れる** | 法面・掘削面は雨水で緩む。**大雨のあとは必ず点検してから作業を再開** |
| **落雷** | 屋外作業・高所作業は中止判断を早めに |

**強風・大雨・大雪等で危険が予想されるときは作業させない**——これは法令上の原則であり、試験にもそのまま出ます。詳しくは → [1級土木 第二次検定 記述問題対策](/posts/doboku-1kyu-2ji-kijutsu)

## よくある質問

### Q1. まず1つだけ買うなら？

**濡れた面にも書ける油性マーカー**です。数百円で、雨の日の「書けない」問題がほぼ解決します。効果を最も実感しやすい買い物だと思います。

### Q2. 耐水野帳は普通の野帳より高いですが、価値はありますか？

**雨の多い時期だけ使い分ける**のが現実的です。梅雨や台風シーズン、雪の現場だけ耐水タイプにして、それ以外は通常の野帳で十分です。

### Q3. レインウェアは作業服の上から着るものですか？

上から着るのが基本です。そのため**ワンサイズ上**を選んでください。ヘルメットの上からフードを被れるかも、購入前に確認しておくと失敗しません。

## まとめ

| 項目 | ポイント |
|------|---------|
| 最優先 | **記録系**（防水マジック・耐水野帳・加圧式ボールペン） |
| 理由 | 体は乾くが、**記録できなかった事実は取り返せない** |
| 持ち物 | 防水バッグ・図面ケースで「濡らしたら止まるもの」を守る |
| 体 | レインウェアは**透湿性**を確認。ポンチョは巻き込みの危険 |
| 手 | 濡れた手袋は素手より冷たい。**防寒より先に防水** |
| 安全 | 滑る・見えない・崩れる。**大雨後は点検してから再開** |

雨は避けられませんが、**「濡れて仕事が止まる」は避けられます**。数百円のマーカー1本から始めてみてください。
