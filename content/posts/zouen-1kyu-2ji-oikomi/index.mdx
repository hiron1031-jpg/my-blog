令和8年度の1級造園施工管理技術検定 第二次検定は **12月6日（日）**。この記事を書いている時点で、残り約10週間です。

造園は情報が少なく、「何から手を付ければいいか分からないまま時間が過ぎる」のが一番の敵です。この記事では、1級造園に独学・一発合格した筆者が、**残り10週間で得点を積み増す順番**を週別にまとめます。

書き方そのものは [1級造園 第二次検定 記述問題対策](/posts/zouen-1kyu-2ji-kijutsu) に譲り、ここは**仕上げに特化**します。

## まず確認：経験記述はもう出ません

ここを間違えると、**10週間まるごと無駄になります。**

<CalloutBox type="warn" title="令和6年度から出題形式が変わりました">
令和5年度（R5）までは**問題1が経験記述**（自分が担当した造園工事について書く）でした。<br /><br />
**令和6年度（R6）から、経験記述は出題されていません**（R6・R7の公式試験問題で確認済み）。現在は**図面・工事数量表を読み取って答える技術記述**が全4問です。<br /><br />
**工事名・工期・自分の立場を暗記する準備は一切不要**です。ネット上にはR5以前の情報がそのまま残っているので注意してください。
</CalloutBox>

### R7の出題構成

| 問題 | 出題内容 |
|------|------|
| **問題1（必須）** | 施工管理（図面・工事数量表に基づく。植栽基盤・移植・植栽・施工管理用語） |
| **問題2（必須）** | 工程管理（**ネットワーク式工程表の作成・計算**） |
| **問題3（必須）** | 品質管理（**公共用緑化樹木等品質寸法規格基準**・透水試験） |
| **問題4（必須）** | 安全管理（移動式クレーン・高所作業車・新規入場者教育） |

**全4問必須です。** 選択問題がないので、苦手分野を捨てられません。

問題用紙・図面のPDFは無料で公開しています → [1級造園 R7 過去問](/pastproblems/1zou/R7)

## 10週間で一番伸びるのは「問題2」です

全4問の中で、**練習量がそのまま点に変わる**のはネットワーク工程表です。

| | 伸びやすさ | 理由 |
|---|---|---|
| **問題2 工程管理（計算）** | **★★★★★** | **答えが1つに決まる**。パターンが決まっていて、練習すれば確実に解ける |
| **問題3 品質管理（規格の数値）** | **★★★★★** | 覚えた分がそのまま点。暗記で埋まる |
| 問題4 安全管理 | ★★★★☆ | 定番の論点が決まっている |
| 問題1 施工管理（図面読取り） | ★★★☆☆ | 図面と数量表の読み取りに慣れが要る。時間もかかる |

**優先順位は 問題2 → 問題3 → 問題4 → 問題1** です。問題1が最後なのは、伸びないからではなく**時間あたりの効率が低い**からです。

<CalloutBox type="point" title="ネットワーク工程表は、造園も土木も計算方法は同じ">
用語を4つ押さえれば解けます。<br /><br />
・**クリティカルパス**＝最も時間のかかる経路。ここが遅れると全体が遅れる<br />
・**最早開始時刻**＝前の作業が全部終わっている最も早い時刻<br />
・**最遅完了時刻**＝全体工期に影響を与えずに終えられる最も遅い時刻<br />
・**トータルフロート（TF）＝0** の経路がクリティカルパス<br /><br />
**過去問を5問解けばパターンが見えます。** 造園の工種名（植栽工・造園土工・修景施設工）に置き換わっているだけです。
</CalloutBox>

## 残り10週間の週別プラン

| 期間 | やること |
|------|------|
| **第10〜8週**（〜10/18頃） | **R7・R6を実際に解く**。答えを見ながらでいい。**問題2の計算を5問**練習 |
| **第7〜5週**（〜11/8頃） | **問題3の品質規格の数値を暗記**。問題4の安全の定番論点を固める |
| **第4〜3週**（〜11/22頃） | **問題1の図面読み取り**に着手。時間を計ってR7を通しで解く |
| **第2週**（〜11/29頃） | 弱い問題だけ解き直す。**数値の即答テストを毎日** |
| **直前1週間** | 用語と数値の確認のみ。**新しい問題は開かない** |
| **前日** | 持ち物・会場・経路の確認。22時就寝 |

<CalloutBox type="point" title="なぜ問題1を後ろに置くのか">
問題1は図面と工事数量表を読み取る問題で、**慣れるまで時間がかかります**。先にここに手を付けると、10週間が全部そこで溶けます。<br /><br />
**計算と暗記で確実に取れる問題2・3を先に固めてから**、残りの時間を問題1に使う。この順番なら、途中で時間が尽きても致命傷になりません。
</CalloutBox>

## 問題3：品質管理で覚える数値

**公共用緑化樹木等品質寸法規格基準**からの出題が定番です。ここは覚えた分がそのまま点になります。

### 樹木の寸法記号

| 記号 | 名称 | 測り方 |
|---|---|---|
| **H** | 樹高 | 地際から樹冠の頂部まで。**徒長枝は含めない** |
| **C** | 幹周 | **地上1.2mの位置**の幹の周長 |
| **W** | 枝張（葉張） | 四方向に伸長した枝の幅の平均値 |

<CalloutBox type="warn" title="Cの測定位置は必ず問われます">
**幹周は「地上1.2m」の高さで測ります。** 1.2m以下で幹が分岐している場合は、**分岐点より下**で測定します。<br /><br />
株立ちの幹周の扱いなど細かい規定もあるので、**手元の規格基準で一度確認**しておいてください。ここは毎年のように問われる場所です。
</CalloutBox>

### 品質の判定項目

| 項目 | 見るところ |
|---|---|
| 樹姿 | 樹形・幹（曲がり・傷）・枝葉の配分・枝葉の密度 |
| 樹勢 | 生育・根鉢・葉（色つや・大きさ）・樹皮・枝 |
| 根鉢 | 根の発達状態、鉢の崩れがないか |

### そのほか押さえる数値

| 項目 | 数値・語句 |
|---|---|
| 客土厚 | 高木**60cm以上**／中木**45cm以上**／低木**30cm以上**／芝生**20cm以上** |
| 地表の排水勾配 | **1〜2%** |
| 暗渠排水 | 地下水位が高い場合、有孔管を布設 |
| 植穴 | 根鉢径の**1.5倍以上**の幅 |
| 支柱 | H3m以上は**八ツ掛け支柱**が目安 |
| 養生 | 幹巻き（こも・幹巻きテープ）で**蒸散抑制・日焼け防止** |

## 問題4：安全管理の定番論点

造園特有の場面が問われます。**土木の安全管理とは出題される場面が違う**ので、造園の文脈で覚えてください。

| 場面 | 押さえること |
|---|---|
| **高所剪定・高所作業車** | **アウトリガーを完全展張**して転倒防止。下方を立入禁止に |
| **墜落防止** | **要求性能墜落制止用器具**（フルハーネス型）を使用。「安全帯」は旧称なので使わない |
| **移動式クレーン** | 定格荷重を超えて使用しない。**旋回範囲への立入禁止**。合図者を定める |
| **強風** | 10分間平均風速**10m/s以上**で作業中止 |
| **新規入場者教育** | 作業内容・危険箇所・使用機械・避難方法を周知 |
| **供用中の公園** | 誘導員を配置し、**来園者と作業区を完全分離** |
| 薬剤散布 | 事前周知、風の弱い時間帯、保護具の着用 |

<CalloutBox type="point" title="即答テストのやり方">
表の左側だけ見て、右側を言えるか試してください。**1周3分**で回せます。<br /><br />
通勤・昼休み・寝る前の**1日3回**。これを10週間続ければ、本番で迷いません。
</CalloutBox>

## 直前1週間でやること・やってはいけないこと

### ✅ やること

1. **数値の即答テスト**（1日3回、各3分）
2. 過去問で間違えた問題だけ見直す
3. 造園用語を声に出して確認する（植栽基盤・活着・根鉢・客土・透水）
4. 試験会場・経路の確認、持ち物の準備

### ❌ やってはいけないこと

1. **新しい問題集・参考書を開く** → 解けない問題が見つかって自信を失うだけ
2. **問題1の図面読み取りを一から練習し直す** → この時期に伸びない。手持ちの解き方で通す
3. **徹夜で詰め込む** → 記述試験は集中力勝負

## 本番の時間配分

第二次検定は **2時間45分**です。

| 時間帯 | やること |
|--------|---------|
| 開始〜10分 | 全4問を一読。**図面のある問題1の分量を把握する** |
| 10〜60分 | **問題1（施工管理）** — 読み取りに時間がかかるので先に片付ける |
| 60〜145分 | 問題2〜4（工程管理・品質管理・安全管理） |
| 145〜165分 | 見直し・誤字脱字・**空欄ゼロ**の確認 |

<CalloutBox type="warn" title="最後の砦：空欄を作らない">
記述式は**部分点**があります。分からない設問でも、関連する用語や数値を書けば点が入る可能性が残ります。<br /><br />
逆に空欄は確実に0点です。**残り20分は「埋まっていない欄を探す時間」**と決めておいてください。
</CalloutBox>

**解く順番だけが自由です。** 問題1に詰まったら、いったん飛ばして問題2の計算に移ってください。手が止まったまま時間を溶かすのが一番もったいない失点です。

**12月の試験です。** 10月の土木とは条件が違います。

## よくある質問

### Q1. 9月の第一次検定に合格できたか分かりません。二次の勉強をすべきですか？

**すべきです。** 第一次の合格発表は10月8日ですが、そこから二次の準備を始めると**8週間しか残りません**。手応えが微妙でも、今から二次を進めてください。仮に一次が不合格でも、**二次の知識は来年そのまま使えます**。

### Q2. 経験記述の例文を暗記していました。無駄になりますか？

**試験対策としては使いません。** ただし**受験申込みの実務経験証明とは別の話**なので、そちらは引き続き必要です。暗記に使っていた時間は、今日から問題2の計算練習に振り替えてください。

### Q3. ネットワーク工程表の計算が苦手です。

**5問解けばパターンが見えます。** 造園も土木も計算方法は同じで、工種名が植栽工・造園土工に置き換わっているだけです。まず[無料の過去問PDF](/pastproblems)でR7・R6を解き、それでも足りなければ1級土木の過去問の工程表問題を流用してください。**計算の考え方は共通です。**

### Q4. 造園の二次は参考書がありません。どうすれば？

**過去問そのものが最良の教材です。** 造園は受験者数が少なく、二次用の教材は限られます。しかも**R5以前の経験記述中心のまま改訂されていない本**が残っています。買い足すなら、**R6以降の現行形式に対応しているか**を必ず確認してください。

### Q5. 残り10週間で間に合いますか？

**間に合います。** 経験記述がなくなったぶん、対策すべき範囲はむしろ狭くなりました。1日1時間でも**約70時間**です。問題2の計算と問題3の数値を固めるだけで、合格ラインが見えてきます。
