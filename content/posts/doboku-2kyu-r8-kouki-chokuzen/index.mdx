令和8年度の2級土木施工管理技士 後期試験は **10月25日（日）**。ここで多くの人がつまずくのが、**第一次検定と第二次検定が同じ日に行われる**という点です。

午前に一次、午後に二次。**一次の手応えを確かめてから二次の準備を始める、ということができません。**

この記事では、2級土木に独学・1発合格した筆者が、**残り約6週間で一次と二次を同時に仕上げる進め方**をまとめます。

---

## 令和8年度 後期の日程と時間

| 区分 | 日程・時間 | 形式 |
|------|------|------|
| **第一次検定** | **10月25日（日）午前**・約2時間50分 | マークシート4択 |
| **第二次検定** | **10月25日（日）午後**・約2時間 | 記述式 |

合格基準はどちらも **得点のおおむね60%以上**です。

> 正確な日程・時間は受験票と [一般財団法人 全国建設研修センター（JCTC）](https://www.jctc.jp/exam/doboku-2/) で必ず確認してください。

今日から本番まで **約6週間**。やることを絞れば十分戦えます。

## 最大の落とし穴：二次を後回しにすると詰む

前期（6月）は第一次だけなので、一次に集中すれば済みました。**後期はここが決定的に違います。**

第二次検定の問題1は**経験記述**——自分が担当した工事について、課題・対策・結果を書く問題です。これは**当日その場で考えて書けるものではありません**。

- 工事名・工期・施工量・自分の立場を整理する
- 課題と対策を数値入りで組み立てる
- 実際に書いてみて、数日おいて読み返し、直す

この工程に最低でも2〜3週間かかります。**だから経験記述だけは、一次の勉強と並行して今すぐ始めてください。**

詳しい書き方は → [施工管理技士 経験記述の書き方【合格の7原則とNG例】](/posts/keiken-kijutsu-kakikata)

## 6週間のスケジュール【一次・二次 並行プラン】

| 期間 | 一次（午前の対策） | 二次（午後の対策） |
|------|------|------|
| **第6〜5週** | 過去問を1年分解いて出題の全体像をつかむ | **経験記述を1テーマ書き上げる**（品質管理がおすすめ） |
| **第4週** | 頻出TOP5分野の過去問を繰り返す | 経験記述を寝かせて読み返し、修正する |
| **第3週** | ×マーク問題を中心に反復 | **2テーマ目**を書く（安全管理 or 工程管理） |
| **第2週** | 重要数値の暗記を毎日 | 問題2〜9の穴埋め・用語を過去問で確認 |
| **直前1週間** | ×マーク問題と数値の最終確認のみ | 経験記述を**声に出して読む**。手書きで1回通す |
| **前日** | 新しい問題はやらない。22時就寝 | 経験記述のキーワードだけ確認 |

<CalloutBox type="point" title="なぜ経験記述を先にやるのか">
経験記述は「書く→寝かせる→直す」を繰り返すほど質が上がります。逆に、直前に詰め込んでも文章の粗が取れません。<br />
一方で一次の暗記は直前ほど効きます。**先に時間のかかるものから片付ける**のが同日受験の鉄則です。
</CalloutBox>

## 第一次検定：頻出TOP5分野

残り6週間で集中する分野です。暗記で得点できる、コスパ最強の5分野です。

| 優先順位 | 分野 | なぜ重要か |
|---------|------|----------|
| ① | **コンクリート工** | 毎年必ず出題。スランプ値・水セメント比・養生日数の数値を覚えれば得点できる |
| ② | **土工・盛土** | 出題数最多。締固め度・含水比・層厚の数値を覚えるだけ |
| ③ | **安全管理（労働安全衛生法）** | 数値（2m以上・85cm以上・10m/s等）がそのまま出る |
| ④ | **施工管理法（工程・品質管理）** | 必須問題が多い。管理基準値の暗記で得点 |
| ⑤ | **法規（建設業法）** | 毎年2〜3問。主任技術者・専任・許可の基本を押さえる |

詳しくは → [2級土木 第一次検定の頻出分野と対策](/posts/doboku-2kyu-hinshutu)

## 覚えるべき重要数値【一次・二次 共通で効く】

同日受験のいいところは、**覚えた数値が午前も午後も両方で使える**ことです。

### コンクリート

| 項目 | 数値 |
|------|------|
| スランプ（一般） | 8〜12cm |
| スランプの許容差（8〜18cm） | ±2.5cm |
| 水セメント比（耐久性） | 65%以下 |
| 普通コンクリートの空気量 | 4.5%（許容差±1.5%） |
| 塩化物含有量 | 0.3kg/m³以下 |
| 暑中コンクリート | 日平均気温25℃を超える場合 |
| 寒中コンクリート | 日平均気温4℃以下 |
| 湿潤養生（普通ポルトランド） | 5日以上 |

### 土工

| 項目 | 数値 |
|------|------|
| 盛土の1層仕上がり厚 | 30cm以下 |
| 締固め度（道路盛土） | 90%以上 |
| 含水比管理 | 最適含水比±2%以内 |

### 安全管理

| 項目 | 数値 |
|------|------|
| 作業床の設置義務 | 高さ2m以上 |
| 手すりの高さ | 85cm以上 |
| 作業中止（強風） | 10分間平均風速10m/s以上 |
| 架空電線の離隔（低圧） | 30cm以上 |

<CalloutBox type="point" title="この数値表は午後にも効きます">
第二次検定の問題7（レディーミクストコンクリートの受入れ検査）では、**スランプ許容差±2.5cm・空気量4.5%・塩化物0.3kg/m³** がそのまま問われます。一次の暗記がそのまま二次の得点になります。
</CalloutBox>

## 第二次検定の構成【選択ミスに注意】

令和7年度（R7）の第二次検定は、以下の構成でした。

| 区分 | 内容 |
|------|------|
| 問題1（必須） | **経験記述**（R7は安全管理・工程管理の2テーマ構成） |
| 問題2〜5（必須） | 品質管理の穴埋め／工程表の特徴／盛土の施工／コンクリート用語 |
| 選択問題(1) | 問題6・7から **1問だけ**選択 |
| 選択問題(2) | 問題8・9から **1問だけ**選択 |

出典：[2級土木 R7 過去問ページ](/pastproblems/2doboku/R7)（問題用紙PDFを無料公開しています）

<CalloutBox type="warn" title="選択問題を2問とも書くと減点">
「せっかくだから両方書いておこう」は**逆効果**です。指定された数ちょうどで解答してください。<br />
また、経験記述の**工事概要や設問1が無記載だと不合格**になります。時間が足りなくても、ここだけは必ず埋めてください。
</CalloutBox>

## スキマ時間×過去問クイズが最強

同日受験は勉強量が多いぶん、**まとまった時間より積み重ね**が効きます。

| タイミング | やること |
|----------|---------|
| 朝の通勤（15分） | 過去問クイズ 5〜8問 |
| 昼休み（15分） | 間違えた問題の解説を読む |
| 帰宅後（20分） | 経験記述を書く・直す |
| 就寝前（10分） | 重要数値をサラッと確認 |

1日合計 **約1時間**。これを6週間続けると **約42時間**になります。

## 試験当日の注意点（10月・1日通し受験）

10月下旬は朝晩が冷え込み、**朝〜夕方まで会場にいる**ことになります。

| 対策 | 理由 |
|------|------|
| 昼食は軽めに（おにぎり2個程度） | 満腹だと午後の二次で眠くなる |
| 黒の油性ボールペン3本以上 | 二次は記述式。フリクションは不可 |
| 羽織れる上着 | 朝は冷え、日中は暑いことがある |
| チョコ・ラムネ | 午後の集中力の立て直しに |

**昼休みの過ごし方が合否を分けます。** 午前の答え合わせは絶対にしないでください。結果が悪いと午後に引きずります。昼休みは経験記述のキーワード確認に集中しましょう。

## よくある質問

### Q1. 一次と二次、どちらを優先すべきですか？

**時間のかかる二次（経験記述）を先に着手し、直前期は一次の暗記に寄せる**のが正解です。経験記述は書いて寝かせる時間が必要ですが、一次の数値暗記は直前ほど効きます。

### Q2. 経験記述に書ける工事がありません。

工期2週間以上の造園・土木工事であれば書けます。現場代理人でなくても「施工管理の補助」として関わった工事で問題ありません。担当した工事で「困ったこと・工夫したこと」を箇条書きにするところから始めてください。詳しくは[経験記述の書き方](/posts/keiken-kijutsu-kakikata)へ。

### Q3. 一次だけ受かって二次は来年、でもいいですか？

制度上は可能ですが、**また1年待つことになります**。同日に受けられるチャンスを活かすほうが合理的です。二次の合格基準も60%なので、必須問題を確実に取れば十分届きます。

### Q4. 残り6週間で本当に間に合いますか？

間に合います。第一次検定は過去問の繰り返し出題率が高く、頻出分野に絞れば得点は着実に伸びます。二次も**経験記述を今日から書き始めれば**十分な準備期間が取れます。焦って範囲を広げるより、この記事の数値表を確実に覚えるほうが近道です。
