令和8年度の1級土木施工管理技士 第二次検定は **10月4日（日）**。この記事を書いている時点で残り約3週間です。

この時期に「まだ間に合っていない」と焦って新しい問題集を買うと、**かえって点数が落ちます**。理由は簡単で、消化しきれないまま本番を迎えるからです。

この記事では、1級土木に独学・1発合格した筆者が、**残り3週間で得点を積み増す進め方**を日別プランでまとめます。書き方そのものは [1級土木 第二次検定 記述問題対策](/posts/doboku-1kyu-2ji-kijutsu) に譲り、ここは**仕上げに特化**します。

---

## 残り3週間の全体プラン

| 期間 | 経験記述（問題1） | 専門記述（問題2〜11） |
|------|------|------|
| **第3週**（〜9/20頃） | 3テーマを**一度手書きで通す**。時間を計る | 苦手分野の過去問を解き直す |
| **第2週**（〜9/27頃） | 音読して矛盾・言い忘れを潰す。数値を入れ直す | **頻出数値の暗記**に集中 |
| **直前1週間** | 音読とキーワード確認のみ。書き直さない | 数値の即答テストを毎日 |
| **前日** | 工事概要と3テーマのキーワードだけ確認。22時就寝 | 新しい問題はやらない |

<CalloutBox type="point" title="なぜ「書く」から「読む」に切り替えるのか">
経験記述は、書き直すたびに良くなるとは限りません。直前期は**覚えて再現できるか**が勝負です。<br />
声に出して読むと、目で追うだけでは気づかない「主語の抜け」「結果の数値がない」といった穴が見つかります。移動中でもできるので効率も良いです。
</CalloutBox>

## 経験記述：この3週間でやる3つのこと

### ① 手書きで、時間を計って通す

本番は手書きです。**パソコンやスマホで書いた文章は、手書きにすると想像以上に時間がかかります。** 1テーマを実際に解答用紙のマス目で書いてみて、何分かかるか測ってください。

3テーマ（品質管理・工程管理・安全管理）それぞれ最低1回は通しておきましょう。

### ② 数値が入っているか、最後に点検する

採点者が見るのは「何をしたか」より「**どう確認して、どうなったか**」です。

- ❌「品質管理に留意して施工した」
- ✅「締固め度90%以上を確認するため、1層ごとに砂置換法で密度試験を実施し、全測点で規格値を満足した」

施工量に「一式」を使っていないかも確認してください。**m・m²・m³・本数**で書くのが原則です。

### ③ 現行の法令用語に直す

古い用語のままだと減点対象になり得ます。

| 古い言い方 | 現在の正しい用語 |
|------|------|
| 安全帯 | **要求性能墜落制止用器具**（フルハーネス型） |
| 一酸化炭素中毒防止… | 用語より**具体的な措置**を書く |

## 専門記述：最後に伸びるのは「数値」

問題2〜11は範囲が広いですが、**穴埋めと数値の設問は覚えた分がそのまま得点**になります。残り3週間で最も費用対効果が高いのがここです。

### 安全管理（届出・作業床）

| 項目 | 数値・語句 |
|------|------|
| 足場（つり足場・張出し足場以外）の届出 | 高さ **10m** 以上 |
| 型枠支保工の届出 | 支柱の高さ **3.5m** 以上 |
| 架設通路の届出 | 高さ及び長さ **10m** 以上 |
| 作業床の設置義務 | 高さ **2m** 以上 |
| 作業床の幅 | **40cm** 以上 |
| 作業床の端・開口部 | 囲い・手すり・覆い（困難なときは**防網**） |
| 悪天候時 | 強風・大雨・大雪等で危険が予想されるときは作業させない |

### 土工・コンクリート

| 項目 | 数値・語句 |
|------|------|
| 締固め管理で試験施工から決めるもの | 1層の**まき出し厚**、締固め回数 |
| 締固めの管理方法 | 締固め機械の**走行軌跡**の管理 |
| 軟弱地盤の管理 | **動態観測**（沈下板・傾斜計・間隙水圧計） |
| 鉄筋の曲げ加工 | **常温**で行う（熱を加えない） |
| スペーサの目的 | **かぶり**の確保 |
| 水平打継目の処理 | **レイタンス**の除去 |
| ガス圧接の検査 | 外観検査＋**超音波**探傷検査 |

### 地下埋設物・施工計画

| 項目 | 語句 |
|------|------|
| 事前確認 | 管理者の**台帳**、位置・連絡先の**表示板** |
| 管理者が不明な埋設物 | 管理者の**立会い**を求める |
| 移設できない埋設物 | 適切に**防護**する |
| 施工計画の基礎 | 設計図書＋事前**調査**、関係機関との**協議** |
| 都市内工事で配慮すること | 労働災害に加え**公衆**災害の防止 |

<CalloutBox type="point" title="即答テストのやり方">
上の表を隠して、左側だけ見て右側を言えるか試してください。**1周3分**で回せます。<br />
朝の通勤・昼休み・寝る前の1日3回、これを3週間続けるだけで定着します。
</CalloutBox>

## 直前1週間でやること・やってはいけないこと

### ✅ やること

1. **経験記述の音読**（1日1回、3テーマとも）
2. **数値の即答テスト**（1日3回、各3分）
3. 過去問で×をつけた問題だけ見直す
4. 試験会場・経路の確認、持ち物の準備

### ❌ やってはいけないこと

1. **新しい問題集・参考書を開く** → 解けない問題が見つかって自信を失うだけ
2. **経験記述を根本から書き直す** → 完成度が下がるリスクのほうが大きい
3. **徹夜で詰め込む** → 記述試験は集中力勝負。睡眠を削ると本末転倒

## 本番の時間配分と、最後の砦

第二次検定は **2時間45分**です。

| 時間帯 | やること |
|--------|---------|
| 開始〜10分 | 全問題に目を通し、選択問題を決める |
| 10〜60分 | **経験記述**を一気に書く（50分以内で完了） |
| 60〜145分 | 専門記述を分野ごとに埋める |
| 145〜165分 | 見直し・誤字脱字・**空欄ゼロ**の確認 |

<CalloutBox type="warn" title="最後の砦：空欄を作らない">
記述式は**部分点**があります。分からない設問でも、関連する用語や数値を書けば点が入る可能性が残ります。<br />
逆に空欄は確実に0点です。**残り20分は「埋まっていない欄を探す時間」**と決めておいてください。
</CalloutBox>

## 試験当日（10月4日）の注意点

10月上旬は朝晩が涼しく、日中は暑くなることがあります。**会場の空調は自分では調整できません。**

| 対策 | 理由 |
|------|------|
| 羽織れる上着 | 冷房が効きすぎる会場がある |
| 黒の油性ボールペン3本以上 | 記述式。フリクションは不可 |
| 昼食は軽めに | 満腹だと集中力が落ちる |

## よくある質問

### Q1. 経験記述がまだ1テーマしかできていません。間に合いますか？

間に合います。ただし**残り3週間で3テーマ**を目指してください。1テーマ書ければ型はできているので、2つ目以降は工事を差し替えるだけで作れます。時間がなければ、出題頻度の高い**品質管理・安全管理**の2テーマに絞る判断もありです。

### Q2. 専門記述はどこまでやればいいですか？

**数値と用語の暗記を最優先**にしてください。長文の論述は本番で組み立てられますが、数値は覚えていないと書けません。この記事の表を確実に即答できる状態にするのが、残り3週間で最も点になります。

### Q3. 過去問は何年分やるべきですか？

新しく解くより、**一度解いた問題の×だけを回す**ほうが効果的です。直前期に新しい年度に手を出すと、消化不良のまま本番を迎えます。

### Q4. 自信がありません。今からでも講座を使うべきですか？

3週間で新しい講座を消化するのは現実的ではありません。**手持ちの教材を仕上げ切る**ほうが確実です。どうしても第三者の目が欲しい場合は、経験記述だけを見てもらう添削サービスという選択肢はあります（申込みから返却までの日数を必ず確認してください）。
